Downloaded from the author's official MP3 link on2026-11-08 for Groove Flight.
The supplied source MP3 is retained unchanged; the game uses a complete Vorbis
transcode. No musical editing, timing, pitch or loudness changes were made.
The game loops the track and mixes it beneath weapons using the background
music category. See `SOURCE.json` for download URL, hashes and conversion data.

The in-game settings screen displays the artist, title, license and source link.
Include this credit and license with distributed game builds. Use the same
credit in descriptions of gameplay videos containing this music, as requested
by the author. Previous project music remains archived under its own provenance.
