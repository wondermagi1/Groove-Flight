# 多声部武器编配 · V9

导入歌曲后，武器应当像小乐队一样分工：旋律、低音、和弦、铺底、装饰音、底鼓、军鼓、踩镲。最多8个声部，每轨可换武器、调音量、声像、静音与独奏。没有识别到某个职责时不会为了凑8轨捏造原曲声部。

## 已有乐谱怎么使用

进入“自由作曲”，点击左上声部列表中的“智能编配”。默认重新分配已有音符，不新增音符，保留音符ID、音高、起点、时值和力度。它会重新平衡音量与声像，保留静音/独奏标记；如果相同职责需要互相冲突的静音状态，操作会拒绝并保留原稿。

如果希望单旋律也有伴奏，勾选“补充缺少的低音与节奏伴奏”。程序按每小节已有音符补缺少的低音、长音和鼓组，新增声部明确标为“新增伴奏”。它是简易自动配器，不是对原曲和弦、调性或编曲的精确恢复；可以删改、独奏检查。

编配前先另存原稿到`%APPDATA%/BeatDriftPrototype/scores/before-arrange-*.beat.json`，失败则不改动作品。旧版1—2轨同一武器、未设置音乐职责且至少8个音符的草稿，在打开工坊时自动重新配器一次，不自动补写伴奏。通过“打开”选择备份可以恢复原稿。

本次只读检查发现现有草稿两个声部都使用pulse，共1109个音符；重新配器可得到5类职责并完整保留音符。开发测试没有写入该真实草稿或保存其中的歌曲内容。

## 重新从MP3识别

“识别 MP3”默认“完整编配”：多音模型估计音符，再按音域、时值、同拍和弦组织定音声部；从低、中、高频瞬态估计鼓组。完成后仍先试听候选草稿，确认才导入。

纯音乐中的钢琴、拨弦也可能被瞬态检测当成鼓点，复杂歌曲还会出现误音、漏音和八度偏差。可逐轨独奏检查并静音错误声部。它不能逐个还原原曲人声、乐器或混音，也不播放原始MP3伴奏来冒充武器演奏。需要精确结果时优先使用整理好的多轨MIDI。

“仅主旋律”保留单音线；“仅多音识别”保留原来高、低两个音域，适合手动改谱。旧版丢掉的鼓点无法凭已有音符恢复，需要重新识别或手动补写。

## 声音与战斗

| 职责 | 默认武器 | 声音 / 表现 |
| --- | --- | --- |
| 主旋律 | 回锋弯月 | 拨弦谐波，回旋弹体 |
| 低音 | 苍穹轨炮 | 稳定低频，穿透弹 |
| 和弦 | 新星环炮 | 多音和声，环形弹幕 |
| 长音铺底 | 轨道护卫 | 慢起音铺底，护卫存续随时值（最多12秒） |
| 装饰音 | 跃迁电弧 | 钟音泛音，电弧连接 |
| 底鼓 | 彗星导弹 | 低频鼓身，单发导弹 |
| 军鼓 | 星砂霰弹 | 噪声鼓皮，最多三发散射 |
| 踩镲 | 星针狙击器 | 高频金属短音，单发星针 |

普通定音声部的MIDI音高保持绝对音高，不按武器预设八度移调。鼓组明确用kick/snare/hat角色合成非定音打击声，不把旋律低音擅自当作鼓。

光束家族的长音会在音符持续期间补充低伤害光束脉冲，使用同一原生音乐时间轴，到音符关闭时停止；卡顿后不补发攻击堆积。所有声部使用同一份音符事件清单驱动音频和首次攻击。自由试飞的击杀、金属命中、爆炸、拾取声降低16dB，其余辅助音效降低6dB，给乐曲留出空间。普通肉鸽仍使用原有采样与平衡。

## 文件与限制

JSON V1新增可选`role`，旧文件默认auto。MIDI第10通道鼓组保留；输出鼓组也使用第10通道。超过8个输入声部会按职责及静音/独奏状态合并，不丢弃尾部声部；混音变化会提示，无法压到8轨则拒绝导入。输入仍受10分钟、256小节、8192音符约束，试飞仍要求每个十六分位置不超过16个起音，超限可继续试听与导出。

详情见[验证记录](TEST_REPORT_V9.md)。当前没有声源分离、自动理解歌词或完美原曲重制能力。
