# V34：武器发声与出膛同步

2026-11-09，`0.34.0-weapon-av-sync`。按用户明确选择，武器只在实际发射时发声；随后将核对范围扩大到全部19件，并更新三件初始配装。

所有行星、难度、舰体和起步预设的新一局使用这三件武器，先保留指定格，再摆放原有非武器道具。下一波不重置玩家的配装。七彩折光匣仍可购买，保留四斜向羽流与2轮充能。

此前“每轮扫描都发声、弹体每几轮发射”会造成有声音却不出弹。现在生产混音与弹体共用发射资格；等待轮不新增起音，已有尾音自然延续。所有武器仍用固定索引0，每次齐射只响一次；同种实例独立叠奏，增加弹排不会增加声音。显式作曲仍按用户编写的音符演奏。

17件实体弹武器每次齐射的首颗立即出现，与声音和炮口闪光同刻起势；后续颗粒保留独立出膛时差、质量、速度、受力与真实尾迹。激光和电弧仍在实际触发时创建，不改成实体弹。伤害、弹数、充能轮数、有效射程与退场规则保留。

音频缓存现在有12秒自然开场，随后循环96秒区域`[12,108)`。开场不再混入上一缓存末尾的“尚未发射尾音”；循环区域在相同充能相位接回，仍有真实尾音衔接。换配装时保留原生播放位置、绝对扫描时间和暂停状态。音序仍1.5秒一轮，敌机仍每0.5秒推进；Filaments与分类音量不变。

[6秒新初始配装试听](audio-v34/starter-synchronized.wav)由当前生产渲染器生成，隔离背景与反馈，包含脉冲、霰弹与流萤的实际发声时刻。[初始配装截图](screenshots/v34-starter-layout.png)用于核对A3、B4、C6–C8。乐器样本未改动：这两件被反馈的素材起音没有明显空白，首个非零采样均小于1毫秒；提琴较缓的起音仍是音色本身。
