# 后续武器模组方向

2026-11-09，用户最新决定。现有实弹体系继续以道具组合和创造性弹道扩展；**导弹、闪电链、激光**成为之后武器拓展的三个重点模组。本文是方向，未把未来条目记成已实现。

| 模组 | 已实现的代表 | 后续可拓展方向（待制作） |
| --- | --- | --- |
| 导弹实体 | 彗星导弹 `missile`：导弹壳体、惯性、追踪、到达后爆炸 | 多级推进、先散后追、曲线绕行、延时分裂或协同锁定；坚持真实到达及预算 |
| 闪电链 | 跃迁电弧 `chain`：目标间连接、稳定分支相位 | 分叉网、导电标记、回路传播、目标/距离限制；不伪装成实体羽弹 |
| 真激光 | 棱镜光束 `beam`：直束光芯/能量鞘、有限穿透接触顺序 | 脉冲、蓄能扫掠、折射、聚焦/展束；保持激光身份及明确有效覆盖 |
| 自由实体弹组合 | 现役羽弹/能量珠；V41新增西风和万花筒 | 受力道具、同轨发射形态组合、万花筒/花瓣/交织等实际弹道，继续沿用粒子、光晕和真实曲线残迹 |

分类看生产 `visual_class` 和真实路径，不只看名字或旧逻辑family。例如双生棱镜 `beam_split` 虽保留beam逻辑属性，现役是实际移动的羽状双流，不是真激光；不要混回旧的刚性彩色束。

万花筒已实现同轨自由实体弹发射形式同步；西风已实现全舰自由实体弹后段受力。两者不改变真激光/闪电链/绑定环绕体，未来如为这些模组增加专用道具，应另写对应的传导/光学/轨道规则，不能复用羽弹速度字段假装生效。

乐器轴与模组轴独立：继续按[统一13乐器方向](ORCHESTRAL_AUDIO_DIRECTION.md)补足声部，安排短充能及3/4/6/8轮长充能组合。新增任何模组都必须遵守[统一武器开发规范](WEAPON_DEVELOPMENT_STANDARD.md)，并在同一提交更新[现役特效/音频对应表](WEAPON_VFX_AUDIO_REFERENCE.md)。
