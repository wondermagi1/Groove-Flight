# 自由作曲工坊 · V9

从主页射击或点击“自由作曲”进入。本模式独立于普通肉鸽当前的双层八格装备音序器，可以写完整的旋律、和弦、低音与休止。当前只显示4个录音原型×3档品质的12个声部音色，电子占位武器暂时不可选择。

## 从一段旋律开始

1. 点击“空白乐谱”，确认替换当前作品；需要保留时先保存。初次进入也可直接试听内置的原创《星港练习曲》。
2. 设置曲名、BPM与小节数。左侧选择声部，右侧选择武器音色。
3. 在中间钢琴卷帘左键写音符。横轴是拍位置，纵轴是音高；允许同拍写多个不同音高组成和弦。
4. 点击音符后，在右侧精确修改音高、起点、长度和力度。拖动音符改变位置与音高，拖动右端改变时值。
5. 添加和声、低音等声部；每轨可独立命名、静音、独奏、调音量与左右声像。
6. 点击“试听”或按空格。音频在后台准备，随后循环播放；编辑内容会停止旧版本，修改后重新试听。
7. 点击“保存”将作品写成`.beat.json`。自动草稿是辅助恢复，重要版本建议另存为独立文件。

| 操作 | 功能 |
| --- | --- |
| 卷帘空白处左键 | 写音符，使用当前长度与力度 |
| 左键音符 / 拖动 | 选中 / 移动音符 |
| 拖动音符右端 | 缩短或延长时值 |
| 右键音符 / Delete | 删除所点 / 所选音符 |
| 滚轮 | 浏览高低音区 |
| Shift＋滚轮 / 左右翻页按钮 | 浏览后面的小节 |
| 显示1/2/4小节 | 改变当前页的时间视野 |
| 左侧琴键 | 短音试听当前武器的音高 |
| 顶部拍号尺左键 | 在已准备的播放中定位；不补发之前的攻击 |
| 空格 | 试听 / 停止；在文字输入框中保持输入用途 |
| Esc / 返回 | 保存草稿并回到进入前的主页或都市 |

勾选“跟随播放”后，页码随播放头移动。其他声部以较暗的音符显示，便于对齐和弦与低音。底部提示过长时可悬停查看全文。

## 把准备好的歌曲编进来

例如想编排《发如雪》，准备该曲的`.mid`或`.midi`乐谱文件，再选择“导入 MIDI”。确认替换后，已有音高、时值和力度会成为可编辑的音符。可以把主旋律分配给脉冲机炮，把和声分配给棱镜光束，再试听并调整混音与BPM。

也可以选择“识别 MP3”，直接分析自己准备的音频，生成可编辑草稿；具体步骤见下文。MIDI保留已有的音符数据，MP3识谱则需要估计音符，因此通常需要更多人工校正。本版没有内置该曲的曲谱、录音或人声，也没有按歌名查找歌曲的功能。试听使用游戏合成音色，不会还原原版歌手演唱。

支持标准MIDI格式0/1，导入后仍可继续编辑。本版采用恒定速度与十六分音符网格：变速、三连音、摇摆等内容可能被统一或量化，操作完成后的提示会说明。第10通道打击乐保留并分为底鼓、军鼓、踩镲。超过8个声部时按音乐职责合并，保留音符并提示混音变化；无法在8轨内保留不同静音/独奏组合时拒绝导入。无效文件会返回错误并保留当前作品。

## MP3识谱

1. 点击“识别 MP3”，选择本地`.mp3`文件，也支持WAV、FLAC、OGG。
2. 默认选择“完整编配”：将多音识别结果按音域、时值、同时发声分成旋律、低音、和弦、铺底和装饰音；分析低/中/高频瞬态生成鼓组估计，最多8轨，各用不同武器。也可选“仅主旋律”或“仅多音识别”，方便手动整理。
3. 默认自动估计BPM。知道原曲速度时，建议关闭自动并手动输入。自动结果可能出现半速或倍速误判，导入后可以校准。
4. 设置起点和长度。长度为0表示分析剩余整首；初次建议先识别20—40秒的清楚旋律片段。
5. 点击“开始识别”。进度窗口可取消；后台组件运行时不会修改当前作品。
6. 结果窗口先点击“试听草稿”。满意后选“导入并编辑”，否则选“保留原曲谱”。导入会替换当前作品，重要原作应提前保存。
7. 在卷帘中删除误音、修正音高与时值、选择武器音色。之后可保存JSON、导出MIDI/WAV或带入试飞。

这是音符转录，不是歌名识别、歌词识别或原版伴奏提取。成品歌曲中的人声、鼓点、混响和多种乐器可能导致误音、漏音、额外八度或重复音；旋律优先也不等于人声分离。单乐器、清晰主旋律和干净哼唱通常更适合作为输入。提高灵敏度会保留更多候选音符，也可能增加误识别。

识谱在本机离线运行，已附Windows x64独立组件，不需要另装Python、注册服务或上传歌曲。单文件最多128MB、单次最多10分钟，同时仍受编辑器256小节和8192音符限制；超限时会提示缩短片段。当前采用恒速、十六分网格，不能完整还原原曲的细微节奏、变速和所有声部。

## 让已有乐谱更丰富

左侧声部列表上方点击“智能编配”。默认保留所有原音符，只重分音乐职责、武器、音量与声像；如果缺少伴奏，可以勾选“补充缺少的低音与节奏伴奏”，新增内容明确标成“新增伴奏”。自动编配不能恢复旧版本已经丢掉的鼓点；要重新从音频估计鼓组，请使用完整编配重新识别。

每次编配前会将原稿保存到`%APPDATA%/BeatDriftPrototype/scores/before-arrange-*.beat.json`。备份失败不修改当前作品。旧版1—2轨同武器且未分音乐职责的草稿，在打开工坊时自动重新配器一次，不额外添加伴奏。可以用“打开”恢复备份。

右侧“音乐职责 / 鼓组”可手动选择自动、主旋律、低音、和弦、铺底、装饰音、底鼓、军鼓、踩镲。乐器、音量、声像、静音和独奏仍能逐轨调整。MP3分类是估计，原曲鼓点与钢琴拨弦可能混淆，可先独奏检查，再调低或静音误识声部。

## 保存与导出

| 功能 | 适用场景 |
| --- | --- |
| 保存 / 打开 `.beat.json` | 保留完整可编辑作品，包括声部、武器、混音与音符 |
| 导出 / 导入 `.mid` | 与其他音乐软件交换旋律、和弦、力度与速度；本程序另带可选的武器和混音元信息 |
| 导出 `.wav` | 输出当前作品的一次完整演奏：22050Hz、16位、双声道PCM音频 |

WAV使用声部音量、声像和力度，不把游戏总音量设置烘焙进文件；尾部空小节属于作品时长。导出在后台进行，“停止”可取消尚未完成的任务。保存使用临时文件写入后替换目标，失败时保留旧文件。

关闭工坊以及编辑停顿约2秒后会自动保存`user://scores/draft.beat.json`，下次启动恢复最后草稿。草稿只有一份，新建或导入并编辑后会覆盖它，因此不能替代另存多个作品。

## 乐谱试飞

“带入战斗”会在所选星球的视觉环境中启动无敌练习。每个实际音符的起点触发对应武器，音乐和攻击读取同一份合成乐谱与原生音频时钟。音高、长度用于演奏；长度不会自动变成持续伤害，和弦会同拍触发多个武器事件。力度会影响这次攻击的基础伤害。

试飞循环乐谱，持续产生练习敌群，没有Boss、波间商店或星球通关奖励。不会写入最高分与星球成绩。可正常飞行、冲刺、暂停；点击“返回作曲工坊”继续编辑，音符保留。普通星球远征仍使用原本装备构筑和规则。

为控制同拍开火数量，试飞每个十六分格最多16个起音。超过时会说明原因，仍可继续编辑、试听与导出。

## 当前边界

- 4/4拍，40—240 BPM，最小十六分音符；C1—C8（MIDI24—108），支持全部十二个半音。
- 最多8个声部、32种武器合成音色、256小节、8192音符、10分钟；实际可用小节数同时受BPM和10分钟上限约束。
- 音频准备最多接受累计3600“音符秒”的重叠合成量；例如一个和弦的各个音要分别累计。过多长音重叠会提示精简，不会无限分配资源。
- 还未支持自由拍号、速度曲线、三连音网格、人声音源、VST、实时录音或撤销历史。音频识谱是需要校正的草稿功能。
- 本模式以可用的游戏内编曲工具为目标，尚未进行真人完整歌曲试听与专业混音验收。

数据格式与MIDI兼容细节见[开发说明](COMPOSER_DATA.md)，本地识谱接入见[技术说明](AUDIO_RECOGNITION.md)，自动测试与实机截图见[V6验证报告](TEST_REPORT_V6.md)。
