## 从起步到结算

[完整原生音乐辅助录像](video-v11/mercury-native-sample.mp4)：水星种子411，实弹起步，5次真实商店、合法货币购买、约156.71秒音频时间，671击破。原生播放器持续驱动，未跳时间、未强制杀怪、未注入装备或免费货币。**辅助为无敌、脚本走位、自动超载与自动购买**，所以不能用它证明真人通关难度。视频1600×900、30FPS，约2分46秒，包含界面与准备时间（GPU截图另在1080p/720p验证），设备录制用时更长。

调度记录155个唯一武器事件：中位16.07毫秒、P95为34.53毫秒、最大37.95毫秒。这是主线程相对原生音频计划时刻的程序差值；不包含实际扬声器、显示扫描及设备额外延迟。录制固定30FPS，不能据此推断正常游玩帧率。短原生音频回归另测最大偏差约6毫秒，负载不同，不合并成一个设备承诺。
