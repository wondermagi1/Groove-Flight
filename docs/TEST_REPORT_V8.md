## 画面与性能记录

实际创建3840×2160 SubViewport并直接用生产材质渲染，未从1080p插值放大。已查看原生地球、木星、土星截图，以及接入新背景后的实际战斗画面和720p设置界面。其余星球也生成独立4K截图，程序检查像素采样结果彼此不同。

OpenGL受控地球4K背景：15帧预热后采样45帧，无截图压缩同时发生。帧间隔中位4.161ms、P95 4.380ms，RenderingServer记录纹理内存约359.83MiB。它包含当时渲染环境的纹理，不是单个材质的独占分配。该数据仅说明本机的短时背景样本，不等于整局FPS、GPU耗时标定、低端机保证或密集战斗性能。

`docs/screenshots/v8-*-background-4k.png`保留Forward+生成的三张4K原图；`v8-earth-battle-1080p.png`为实际原生短飞行截图，`v8-settings-720p.png`为实际设置控件截图。全八星原始检查图位于忽略版本管理的`work/uhd-review`，可用脚本重建。

源素材分辨率有差异，具体见[UHD说明](UHD_BACKGROUNDS.md)和[来源记录](../assets/planets/sources.json)。天王星、海王星并非8K源图。未进行八条完整航线重跑或真人长期平衡验收，Boss与武器规则沿用V7。
