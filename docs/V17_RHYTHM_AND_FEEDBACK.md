# V17 独立武器拍序与录屏反馈

日期：2026-11-04。工程版本：`0.17.0-independent-groove`。

## 当前玩法

- 保留V16的32把电子武器与三轨8格，录音武器暂时隐藏。初始仍是七彩折光匣和螺旋星冕。
- 统一音频扫描与界面：每格0.125秒，每轮1秒。修复实际音频扫描残留0.25秒的问题。
- 所有当前可用武器按自己的强弱型跨轮推进，每轮只执行一拍；四拍分别在相对0、1、2、3秒，4秒开始下一组。单拍多弹丸不等于多个拍序事件。
- 声音的音高/强度与伤害使用同一事件；四拍强度总量保持原四轮输出。充能门槛继续保留，未充能的拍只发声、不产生弹体或伤害。因此两轮充能武器不是每秒都产生真实齐射。
- 每件装备按UID保存下一拍，挪格保留下一拍；卸下后再装备从第一拍开始。新装配的武器从自己的第一拍开始，与其他武器独立。
- 音频重编译前，为每件武器计算下一次扫描的相位偏移；编译不会推进武器状态。128秒原生音轨清单与真实弹体使用相同偏移。
- 商店手动试射使用相同调度，从0秒开始，循环预览为4秒，且不改正式配装、货币或随机状态。商店不自动开启试射。

## 实际触发规则

- 死亡低鼓在敌人真实死亡的回调里立即开始，不等整拍或聚合窗口。
- 同时大量击杀聚合为最多3下后续鼓，每下至少间隔125ms；强、弱、圆润低鼓交替。连杀提高有限力度，不持续升高音调。
- 卡帧后不把积压鼓点挤到同一帧；进入商店清空尾鼓，暂停/编辑时冻结击杀反馈。
- 普通命中不再重复播放此前那段重低频撞击，不再因为打中敌人就刷新玩家无敌护盾。非致死命中保留较轻金属反馈，死亡才触发主要低鼓。
- 玩家实际扣血后展开3秒保护护盾；消耗已有护盾格时也播放护盾受击声。击杀低鼓、受击警报、金币拾取使用各自音频池，避免相互抢声。
- 拾取只改变音效，不改变金额、磁吸、回血或掉落规则。
