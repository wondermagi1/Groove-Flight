# V10 武器渲染

> 2026-11-05最新：用户已确认12种保留武器，当前清单与乐器音色见[V19十二种武器](V19_SELECTED_TWELVE.md)。本页其余数量和试听信息作为历史资料保留。

> 2026-11-05：当前以[V18固定声音](V18_FIXED_VOICES.md)和[32种武器—特效筛选清单](WEAPON_SELECTION_32_TO_10.md)为准。下文版本数量、录音启用状态、旋律和强弱规则含历史内容。

本次改进覆盖44个武器品质条目的12个家族，同时用于普通肉鸽和自编乐谱试飞。当前12个可作战条目来自4个授权录音原型的三档品质；32个电子占位武器保留渲染档案但暂停实战。

额外添加短时炮口辉光、命中星芒与填充碎屑；爆炸使用膨胀冲击波、短促中心亮点和放射火花。没有大面积烟雾、全屏白闪或屏幕扭曲。

这是2D着色器的表面明暗和自发光模拟，不是新建3D武器模型。光晕直接在局部几何上计算，不依赖屏幕Bloom；Forward+和兼容渲染器均能显示。没有新增外部付费资源或下载素材。

## 可读性与设置

- 飞行中的弹体仍沿原有方向、追踪、回旋和轨道路径运动；伤害、碰撞半径、穿透、爆炸伤害与音乐驱动规则不变。
- 敌方子弹在独立上层绘制，保留粉红危险色、暖白内芯，并增加暗色分隔轮廓，避免埋在己方光晕里。
- 全场友方弹体超过650时降低光晕强度，实体仍全部保留；有离屏裁剪。
- 设置中的低特效开关关闭弹体外层光晕，保留实体、激光与危险提示，降低碎屑量。无须修改装备。
- 特效使用模拟寿命和弹体年龄，不使用shader TIME推进，暂停时动画冻结。
- 命中特效对同一敌人限流，避免持续伤害每帧堆积星芒；这不限制伤害与击杀计数。

## 实现与预算

`scripts/weapon_render.gd`用共享QuadMesh和12组MultiMeshInstance2D绘制弹体，每组分实体和发光两个Pass。最多1200个友方弹体，与原战斗上限相同；不为每颗子弹新建节点。三个着色器分别负责实体、光晕与短时特效。

`scripts/fx.gd`保留burst/ring/beam/number接口，并添加muzzle/impact/blast。短时特效以一个实例批次绘制，上限144条；碎屑以一个三角形网格批次绘制，上限850片。低特效模式限制新生成碎屑至240片，既有短时碎屑自然结束。数字和环形提示继续保留。
