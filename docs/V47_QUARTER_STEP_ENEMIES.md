# V47 敌机推进与实弹成长

2026-11-10，`0.47.0-quarterstep-enemies`。修改推进前备份`a948e86317f33c56d429bc4f47c65d566521f0de`，加入实弹成长前备份`53b3b90d0cb1e38f3f4803f6632800e47dde5f4d`，均已上传并核验远端SHA。开发分支`codex/quarterstep-ballistic-growth`。

## 敌机节奏

普通敌机使用独立时钟：每0.25秒规划一次，0.16秒以三次缓出曲线完成移动，随后停顿0.09秒。非部署行进速度倍率1.20，单步位移为旧0.5秒步进的60%；转向上限由每旧步0.5弧度改为每新步0.25弧度，保留每秒1弧度的惯性。

`enemy_cadence.gd`统一追击、后备追击、矩阵部署起点及前瞻。矩阵仍约3秒平滑向上下战场展开，中部连续过渡；圆阵仍先径向展开，再按个体近攻/绕行。完整机身净空、扫掠避让、视野外包围与近端弧形进攻保留。出生预算与原0.5秒生成调度未加倍，精英/Boss时序不变；普通敌机不射击。

Windows原生数值内核接收同一新计划，C++、DLL与`.gdextension`均未改动，无需重建二进制。武器音序器仍每1.5秒一轮、每格187.5毫秒。

## 实弹开局与波末强化

实弹流每个新局在基础属性层获得实弹+10，覆盖全部星球、难度与机体。不会占音序器格位，也不依赖某件核心保持装备。初始武器仍是A3脉冲机炮、B4–B5苍穹轨炮；流萤织雨仍由商店获得。激光流与闪电流不继承这10点。

波末三选一保持每波只能选一次。实弹流固定抽取两项不同的实弹强化和一项通用强化，展示位置随机；移除实弹流波末的支援+5、能量+5与动力+5。生命、护甲、机动、再生、拾取、幸运、暴击和全武器单发伤害仍在通用池中。商店装备池不因此重写。

| 实弹强化 | 抽取权重 | 结算 |
| --- | ---: | --- |
| +3 / +5 / +7 / +10 | 各3 | 当场加点 |
| ×1.5 | 2 | 当前实弹乘一次 |
| ×2 / ×3 | 各1 | 当前实弹乘一次 |

倍率按用户确认采用一次性快照：例如10点选×2得到20点，之后+7得到27点。实现读取点击时的当前总实弹属性，含已装备道具；把`目标值－当前值`记录为本局加点。之后获得或卸下装备按正常加减处理，不保留永久倍率。统计刷新、图鉴预览克隆、暂停与跨波不能再次乘算；新局清空波末奖励，恢复开局10点。属性来源可查看“实弹流开局”和“波末倍率已结算加成”。

现行属性上限1000、实体弹单次上限256继续生效。每点归属属性增加1发的共享公式、品质和强化加弹、伤害公式继续使用；因此新属性会真实增加相应武器弹数与伤害。不同归属属性的实体武器仍按各自属性计算。没有更换音源、增加额外声音或改变基础齐射形式。

## 对此前实弹变弱的核查

- V35为音乐留白延长多件范围武器充能，但没有按相同比例增加单次基础伤害和弹数。例如尾羽1→3轮、新星1→4轮、七彩2→4轮，持续弹量会降低；V38后来扩大射程与覆盖，不能等同于补齐单点持续输出。
- V40把普通机基础HP提高约33%–43%，同时增加生成预算，清怪压力提高。
- V43移除了开局流萤织雨，并取消旧`starting_path`预设的开局装备；旧实弹预设中的弹道总控核曾提供实弹12、暴击4%、穿透1，现在本轮按用户最新要求恢复为基础实弹10，并不自动赠送整件核心。
- 核对的V35及之后，现役实弹武器单次基础弹数未下调；万花筒由44提高至96。画面密度还受充能间隔、属性与装备、真实命中和飞行时间影响。

这次按用户明确要求修复开局属性、强化供给和敌机节奏，没有额外重写全部武器的基础伤害/充能数值。

## 验证与边界

专项验证涵盖精确0.25秒边界、160毫秒移动/90毫秒停顿、四秒16步、速度倍率、出生对拍、暂停冻结、矩阵前瞻；原生/脚本端点一致性、600架15秒矩阵与144架52.5秒圆阵；400组强化抽取、全部七种选项、快照倍率、后续加点、装备更换、克隆/重开/上限及实际商店按钮。

600架3秒部署面积为初始约9.22倍，无原地滞留单位；15秒末600架均移动超过20单位，仅5架处于局部等待。圆阵97架曾离开镜头，40架在观察期内返回。两者净空误差均在0.02游戏单位测试容差内。

1024架、八件Lv.4武器、1920×1080 Forward+的两段各16秒受控密集测试保留全部敌机与武器发射，无普通机远程弹和末尾待发弹积压。帧耗时P95约23.14/25.95毫秒，最大33.56/42.10毫秒，仍有峰值；这是隔离机制测试，不能据此承诺整局持续60FPS，也不是加入倍率后的真人平衡验收。
