# V8 · 高清行星背景

八颗星球已接入表面贴图与新的逐像素球面材质。默认背景画质为“超清”。打开设置可切换画质或调节背景亮度，旧存档缺少这些设置时自动采用新默认值，星球成绩和乐谱仍使用原存档服务。

## 画质与显示

| 档位 | 表现 |
| --- | --- |
| 标准 | 表面贴图与基础球面光照 |
| 高 | 增加大气层、地球云层和夜侧灯光 |
| 超清（默认） | 增加法线/微地形细节、云影、海洋反光和气态行星细节；降低原后处理扫描线强度 |

三档使用同一套高清源贴图；档位控制附加光照计算，不承诺切换后降低源贴图内存。亮度独立调节为35%—125%，默认90%，便于兼顾环境表现和弹幕辨识。设置内容可滚动，“保存并返回”固定显示，720p窗口下仍可操作。

保持1920×1080逻辑布局与`canvas_items`拉伸，实际渲染随窗口/全屏的像素尺寸。4K显示器上的原生全屏可以使用3840×2160；1080p显示器仍输出1080p，高清素材会改善细节，但不会改变屏幕本身的像素数。已使用真正3840×2160 GPU渲染目标检查八个背景，不以放大1080p截图代替。

## 美术来源和实际分辨率

素材来自[Solar System Scope](https://www.solarsystemscope.com/textures/)，按其标注的CC BY4.0署名使用。源文件不做插值放大，尺寸来自实际解码核验，不能仅由文件名判断。

| 地图/图层 | 实际像素 |
| --- | --- |
| 水星表面 |8192×4096 |
| 金星大气 |4096×2048 |
| 地球白昼、夜景、云层、法线、反射遮罩 |各8192×4096 |
| 火星表面 |8192×4096 |
| 木星表面 |4096×2048 |
| 土星表面 |4096×2048 |
| 土星环透明带 |8192×500 |
| 天王星表面 |2048×1024 |
| 海王星表面 |2048×1024 |
| 银河星空 |8192×4096 |

木星与土星下载名带“8k”，文件实际宽度为4096；本版按实际值说明。天王星/海王星保持源分辨率，连续球面光照、大气层与细环在当前输出分辨率下计算。完整署名、许可、下载URL、SHA256和TIFF转换说明见[素材记录](../assets/planets/CREDITS.md)及`sources.json`。

## 运行与内存

`planet_backdrop_assets.gd`按当前星球绑定表面，不预加载所有行星。地球专用云层、夜景、法线与遮罩在切换到其他行星时解绑。星空为共享资源；土星才绑定土星环贴图。

贴图保留原尺寸，启用mipmap和高质量VRAM压缩；材质使用三线性mipmap和各向异性采样。环带先绘制远弧，再将近弧合成到球面前方；球体边缘按像素导数抗锯齿。地球的云影、夜景遮蔽、海洋反光和法线为独立图层。岩质行星还有轻微的亮度浮雕提示，不把照片亮度宣称为真实高程。

本机RTX4060 Laptop的受控4K地球背景样本记录见测试报告。该测量仅含背景，不能用于保证密集敌群下的整局帧率。

## 重建与预览

```powershell
python tools/fetch_planet_textures.py
python tools/configure_planet_imports.py
```

下载脚本需要Python与Pillow，运行游戏不需要这些工具或网络。首次Godot导入会生成较大的本地纹理缓存，完成后后续启动复用缓存。游戏内不自动下载素材。
