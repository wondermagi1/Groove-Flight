# 逐星开发顺序

2026-11-17：先修数值底座，再逐星做完整体验。每轮改动先上传Git备份、完成后上传检查版本。

V61第一轮已实现：准确率平方弹量、成长收益收敛、逐波耐久与BossHP初标；水星大航标、导航与采样反馈；更亮的银河星海。[当前实现](V61_MERCURY_RHYTHM_BALANCE.md)。这些受控检查不等于八星真人难度已验收。

接下来依次推进：

1. **水星完整一局**：先试玩开场与七波的成长/补给，关注50/80/100%成绩下的走位压力、是否有无解包围、目标能否一眼找到。优先把该首关做成左右手协作的教学关；再精修Filaments指法和手势节奏，给移动/冲刺留出反应空间。
2. **水星Boss**：攻击前摇、安全通路、节点/核心暴露和阶段反馈。当前只初标耐久，未重做攻击；不依靠血墙拖时间。用实际配装/节奏成绩检验。
3. **金星护送**：让路线、护送艇模型/耐久和拦截方向更直观，制造跟随与提前拦截的选择，再优化金星Boss。
4. **后续每星分别做任务→模型/引导→Boss**：地球防守、火星据点、木星追猎、土星航门、天王星共振、海王星多阶段终章。每星完成后再扩到下一星，避免同时铺开八套半成品。

贯穿各星的三个优先方向：歌曲指法与双手负担；危险/目标/命中反馈的可读性；构筑成长有爽感但不能绕过音游。难度谱面、复杂手势、专属击键音等均需单独开发与验证，当前不宣称已完成。
