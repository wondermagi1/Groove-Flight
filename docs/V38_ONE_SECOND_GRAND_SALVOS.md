# V38：一秒演奏与长充能齐射编排

2026-11-09，`0.38.0-one-second-grand-salvos`。按最新连续反馈，最终以**1秒**覆盖中途讨论的2秒、1.5秒；十件三四轮武器同时升级实际发射形式和覆盖范围。流萤改为与尾羽同色系的彩虹弹幕。

## 声音

新星、七彩、终压、鎏金、虹织、星冕、尾羽、晨羽、潮汐、流萤的四档演奏共40份，全部为22,050帧／22,050Hz，精确1秒，包含平滑收尾。四档音色/力度、固定根音与声学弓弦组合保留；强/很强仍沿用V37的起音增益。持音0.6秒、释放0.4秒，末35毫秒淡出，没有用静音填长或改变播放速度。其他36份力度样本与152份作曲音高样本保留，总计228份。

普通实战仍按当前有效充能只在真实齐射时发声；一轮很弱→弱→强→很强，二轮弱→强，三轮强→很强，四轮很强→强。新增弹排、方向和展开层不增加发声次数；齐射首弹立即出膛，后续独立出膛编排不超过550毫秒，一秒声音覆盖这次展开。

策略：[WEAPON_DYNAMICS.json](../audio/instruments/WEAPON_DYNAMICS.json)。清单与SHA：[DYNAMICS_MANIFEST.json](../audio/instruments/DYNAMICS_MANIFEST.json)。[流萤强奏1秒](../audio/arsenal/dynamics/dyn_firefly_rain_2.wav) · [流萤很强1秒](../audio/arsenal/dynamics/dyn_firefly_rain_3.wav)。旧长音元数据见[修改前清单](../audio/instruments/archives/DYNAMICS_MANIFEST-before-v38.json)。重建时使用`tools/build_weapon_dynamics.py --ids ...`，默认生成这十件的四档，不再只重建2/3档。

用户提出管弦大鼓、定音鼓等作为重武器音色方向；本轮先完成已明确的一秒音源和彩虹/齐射要求。打击乐替换属于后续配器方案，当前没有宣称已装入鼓或镲片。
