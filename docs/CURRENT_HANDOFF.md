# Groove Flight 当前接手说明

2026-11-07，工程版本 `0.22.0-attribute-barrages`，开发分支 `codex/v22-attribute-barrages`。远程仓库：https://github.com/wondermagi1/Groove-Flight 。后续每轮游戏修改前必须先上传Git备份并核验SHA，规则见根目录 `AGENTS.md`。

优先阅读 [V22属性弹幕与局部柔光](V22_ATTRIBUTE_BARRAGES.md) 和 [方阵与圆阵的分布、追击、包围与建模](ENEMY_FORMATIONS_AND_ENCIRCLEMENT.md)。最新出生方向是上方、左上方、右上方，覆盖V21.1的侧后方偏好。较早的“只使用方阵”已扩展为方阵与圆阵两类；未引入菱阵。

## 当前规则

- 音序器3轨×8格，每格0.125秒、一轮1秒。扫到武器起始格播放一次固定音色，同种武器不同实例允许尾音重叠。四拍强弱与自动旋律继续搁置，拍序状态条已移除。
- 原有12种武器全部保留，新增鎏金螺旋阵、虹织十字炮、星冕回旋阵，共15种。商店、试装、图鉴与显式作曲走同一可用名单。
- 弹数=基础+对应主属性（默认每点1发）+品质档位×2+强化等级−1+原有改件。品质随合成等级提升，最高传奇；普通弹体/激光/电弧起始分支上限256/128/64，面板显示数量和上限。弹数增长参与实际命中，固定声音不随弹排重复。
- 实体弹保留完整短弹头、短尾迹与柔光，每排间隔45毫秒。高数量激光收细并拉开独立束芯。不能为增加密度恢复大片长尾光，也不能把光晕全部取消。
- 普通敌机不射击，每0.5秒推进一次，以接触造成伤害。精英与Boss保留专属攻击。
- 每批同型号。出生只选上方、左上方、右上方，整片出生区域至少高于玩家360单位，展开路径也留净空；预警结束时复算展开方向并复查安全。无安全位置时等待，镜头外有红色方向提示；方阵显形后用约3秒向上下大战场疏散，中部以连续权重向两侧扇形过渡；圆阵显形后先径向展开。约32%近端单位先攻，其他单位分向两翼并沿地图坐标绕行。
- 近端形成扇形、弧形压力，远端在视野外继续行动；每架有自己的路线进度、朝向与局部避让。舰体保留净空，分裂出生也寻找空区。
- 战场镜头缩放0.65；玩家绘制核心半径16，普通机16—18游戏单位，完整外形与核心半径不同。敌机采用带侧壁、顶面与固定世界受光的实例网格，营造2.5D俯视感。
- 后期大矩阵验证600架、25×24，普通敌机存活上限1024。扩大密度仍要结合性能和真人难度检查。
- 受击后蓝白色核心亮光与保护场衰减；实际保护时间仍为3秒。现有击杀低鼓、受击/拾取反馈继续保留。
