# V46 UI回退与战斗顶部透明化

2026-11-10，`0.46.0-clear-combat-ui`。用户先要求UI也回退，再明确战斗顶部青色UI影响观感，希望透明化。修改前备份已上传核验，SHA见[本轮验证](data-v46/SUMMARY.json)。

主界面/HUD/设置、商店/音序工坊、星图、机库、音色图鉴、作曲页恢复 `059ceb2` 的原始UI样式。随后仅对战斗顶部的操作入口应用透明材料：暂停、编辑、跳过教学，以及属性/状态/增益/背包/音序开关和显示全部。保留原点击区域和信号，普通与禁用状态无底色、边框和阴影；悬停只有10%暗底，按下18%暗底。文字采用白色文字及细暗描边，保持在星球背景上的辨识度。

移除V44常驻的整条顶部衬板，Boss信息衬板也透明。生命、倒计时、货币、击破数、Boss血条、超载状态和恢复音序器入口保留。菜单和商店按钮继续使用原来完整的背景与交互反馈。

V45原始星球/星空背景、V44五种我方与八类普通敌机的细节优化继续使用。24武器、288份音源、充能/节奏/弹道、流派与初始配置、敌机行为/碰撞、数值和原生群体内核保持。V44共享皮肤文件留作历史，生产UI已不再引用它。

使用已有商店/HUD、详情固定和流派回归检查，无新增玩法测试。图鉴、机库、星图和作曲页与原始UI源文件逐字节核对；UI与商店源文件的附加改动仅为上述战斗透明样式。详见[验证汇总](data-v46/SUMMARY.json)。7页介绍PPT保留，未覆盖正在打开的文件。

后续反馈要求白色文字与醒目的倒计时：顶部状态和按钮使用白字，未展开的开关保持80%白色区分状态。倒计时从35号提升到56号粗体（字重700），配3像素暗描边，并限制大文字模式下的最大字号以保留横向空间；开关行根据计时文字高度向下避让。135%文字下的BOSS标记宽151、右边缘343，生命从370开始；计时下沿80、开关行88，均无交叠。
