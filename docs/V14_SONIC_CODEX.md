# V14 武器音色图鉴与录制音频实装

版本：`0.14.0-sonic-codex`。记录日期：2026-11-03。

## 本轮目标

- 从已授权录制素材中先实装一批可分段的短音效。
- 将粗制火弹、实弹轻/中/重音变成可进入商店和音序器的新武器。
- 图鉴左栏按34个武器原型去重显示；录音武器的6个品质条目集中到右侧详情切换，32个电子占位条目保留档案但停用。
- 所有武器都有四拍节奏结构，但允许持续等强；只有部分武器承担重击或渐强。

## 新武器

两个录音原型各自直接播放一个连续录音事件组，不做内部分段或升降调；每个原型提供普通、稀有、珍贵三档：

| ID | 名称 | 家族 | 伤害/弹数 | 特点 |
| --- | --- | --- | --- | --- |
| `recorded_crude` | 裂响火弹 | 机炮 |15×2|粗制火弹重音、短寿命高密度弹道 |
| `recorded_ballistic` | 实弹连奏炮 | 机炮 |11×3|统一实弹16秒素材（4个四拍周期），三档品质改变弹数与伤害 |

| 武器 | 直接播放原声组 | 源区间 |
| --- | --- | --- |
| 裂响火弹·普通/稀有/珍贵 | `audio/authorized/weapon_crude_fire_group_6s.wav` | `0.00-6.00秒` |
| 实弹连奏炮·普通/稀有/珍贵 | `audio/authorized/weapon_ballistic_cycle_16s.wav` | `0.58-16.58秒` |

两份原声组文件是48kHz双声道PCM16，截取后没有再做淡化、增益、归一化、重采样、内部分段或变调。三档品质共用各自原声组，不会互相拼接。`audio/arsenal/notes/rec_crude_*`与`rec_ballistic_*`继续记录源事件区间与兼容用途。

## 四拍节奏体系

音序器每1秒循环一次；武器每被白点扫过一次推进一拍。裂响火弹为2拍强-弱（2秒），实弹连奏炮为4拍（4秒）。强度是相对占比，伤害按“占比×本地拍数”换算。

| 节奏型 | 四拍强度 | 武器 |
| --- | --- | --- |
| 匀速四连 |25/25/25/25|机炮、光束、轨道卫星、无人机等10件 |
| 重-轻-轻-轻 |46/18/18/18|霰弹、导弹、轨炮、雷荚等13件 |
| 渐强 |12/20/28/40|光束、电弧、焰流等8件 |
| 轻-重-轻-重 |18/32/18/32|环炮等2件 |
| 强-弱-强-弱 |32/18/32/18|回旋刃等3件 |

充能武器在尚未满足充能时仍会在四拍发声，但不会生成伤害。满足充能的拍会依照该武器的强度型分配真实伤害和弹体。

## 武器图鉴

入口：

- 标题页“武器音色图鉴”
- 音序编辑器和商店顶部的“音色图鉴”按钮

图鉴功能：

- 左栏只列出34个武器原型，同种武器的品质不重复占卡。
- 录音武器详情内有普通、稀有、珍贵切换和三档数值摘要。
- 6个录音品质条目标记“录音原声组”，32个电子占位武器标记“音源停用”且不可试听。
- 显示家族、充能、占格、节奏名称与四拍强度。
- 显示实际音源 voice、8/8样本切片、单样本字节数和SHA256前缀。
- 合成武器可逐音高试听；录音武器直接试听战斗使用的连续原声组。
- 图鉴打开期间暂停标题页主背景音乐，避免掩盖试听。
- 图鉴为只读，不会改变配装、货币、RNG 或战斗回执。

离线总记录为 `audio/weapon_codex.json`：38个武器品质条目、288个唯一PCM样本文件；每个样本均记录路径、字节数与SHA256。6个录音品质条目共用2段连续原声组，并记录源文件起止秒数与“PCM16直接截取”处理标签。最终测试和音频清单快照同时保存在 `docs/data-v15/`。

## 已知边界

- 当前实装：菜单、两段录音武器周期、碰撞/护盾/生成、推进器，以及所有关卡共用的10小节战斗/商店循环音乐。
- 四件录音武器的战斗原声已改为连续组直接播放；后续新增录音仍须先完成全段波形、有效事件和源起止分析，再登记为运行文件。
- 授权证明目前是用户确认文字，正式发行前应把截图或书面许可放入 `authorization/`。
- 四拍命中结构提高了弹丸更新频率，极端高密度场景仍需继续观察性能。
- 当前工程没有 `export_presets.cfg`。正式导出前，导出预设必须包含 `audio/arsenal/notes/*.wav` 与 `audio/authorized/*`，或先在 Godot 编辑器中完成这些音频资源的导入；开发版已经对录音 WAV 提供文件加载回退。
