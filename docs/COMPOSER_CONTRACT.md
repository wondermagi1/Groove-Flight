# 自由作曲模式接口

Score: scripts/composer_score.gd RefCounted. title,bpm40..240,bars1..256,4beats/bar,tracks<=8,notes<=8192,total<=600secs. Track{id,name,weapon,volume,pan,mute,solo,notes}; Note{id,beat,duration,pitch MIDI24..108,velocity1..127}. Grid0.25beat (sixteenth), chords legal. APIs reset_demo/empty/validate/to_dict/from_dict/add_note/remove_note/change_note/add_track/remove_track/set_bpm/set_bars/duration_seconds/step_seconds/step_count/schedule/import_midi/export_midi/save_json/load_json. File loads atomic. Original demo only, user-provided MIDI for existing songs.

Player: scripts/composer_player.gd AudioStreamPlayer, nativePCM stereo22050, worker begin(score,loop=true)->bool with immutable snapshot. Signals playback_started,compiling_changed,event_fired(event,deadline),step_fired(index,serial,deadline),finished_song. timeline,step_duration,loop_count,last_step,_running,compiling,score_events,compile_msec. compile(score),rebuild(score),hold(bool),stop_song(),pulse(),export_wav(path,score)->{ok,error}. Samples respect absolute MIDI pitch, duration,velocity,track gain/pan/mute/solo. Root validation rejects trial onsets>16perstep; audio preview/export retains all valid notes.

UI: scripts/composer_screen.gd Control var game, states composer/composer_loading, own file dialogs/piano roll and 8track navigation. game.composer_score/player/status plus callbacks composer_play/stop/save/load/import_midi/export_midi/export_wav/changed/battle/close_composer. Pure UI edits call composer_changed(), which stops preview safely. Root adds title entry and main lifecycle only.

Trial: root aliases game.music to composer_player only in free_music_run=true, restores standard_music afterward. Non-ranked invulnerable test arena, no normal shops/planet records. New notes fire authored weapon events; shared native player step drives enemy motion patterns/spawns. Trial controls pause/resume/return to composer. Score is preserved. No external songs or commercial-score transcriptions bundled.
