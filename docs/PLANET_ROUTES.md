# 律航 · 太阳系行星航线

本版把出击目的地分成八颗行星。玩家在微缩3D太阳系中选择行星，再进入该星球的2D节拍战斗；太阳是星图中心。全部行星可直接选择，推荐顺序从水星到海王星，通关与最佳成绩用于记录进展。

星图采用便于选择的示意比例：轨道半径3.0—14.7、行星显示半径0.45—1.0，不按真实天体距离绘制。行星主题、战斗数值和波次都由`planet_catalog.gd`提供。这里的配置是《律航》自行编排的数据，不是参考游戏的内部关卡数据。

“生存段时长”仅相加固定生存波次，不包括Boss击破、商店编排和停留时间；不是完整通关用时保证。普通预算不含精英、分裂出生及Boss护航。生产时仍受敌机、弹丸和单批生成上限控制，不会一次生成整波预算数量。

各关前段使用20—45秒生存波，倒计时完成后进入现有波间商店。最后一波为Boss击破目标，时长由实际伤害决定。行星顺序越靠后，难度同时来自敌人耐久、伤害、移速、弹速、密度、角色配合与终点压力，不能仅凭波数理解难度。

Boss生命为独立绝对值，不能再重复乘普通生命倍率。敌人接触、普通弹与危险射线都应走相同的行星伤害缩放；玩家的护甲、暴击、治疗及武器属性继续由原装备系统结算。

星屑使用小数余量累计。例如1.08倍的普通掉落先产生1颗，未满1颗的部分累计到后续掉落，不能简单四舍五入后让前几个星球的奖励加成消失。余量在新一轮出击时重置，失败或返航不额外制造奖励。星屑仍是本轮购物资源，不代替永久技能树或跨局战力。

后期生命与伤害增长快于移动速度，保持可观察、可回避的攻击。更强的行星允许玩家直接挑战，但应当通过星图威胁等级、数值和战术提示说明风险。此表是初始平衡，不代表未经装备规划即可通关海王星。

## 每个航区的阅读线索

V7战斗背景逐星球绘制球面、明暗和大气层：水星撞击坑、金星硫黄云层、地球海陆云带、火星峡谷与极冠、木星云带和巨斑、土星透视光环、天王星冰青极轴与细环、海王星深蓝风暴。都是游戏化程序美术，不是天文贴图或精确地表模拟。

机器核心碰撞半径158—214世界像素，外侧炮组、钻臂或旋转轨道进一步扩展轮廓。核心与主装甲可命中；外围机械附肢为装饰。所有机器有2.4秒入场保护时间，期间不能开火；半血进入核心过载。Boss生命、伤害倍率与章节波次继续使用前述航线数据。放大后弹丸从装甲边缘发出，避免弹幕在舰体内部隐藏一段时间才出现。

## 音乐、表现与成长衔接

八条航线继续共享现有原生音乐播放时钟，武器、旋律和出怪拍点没有另开互不相关的计时器。不同关卡的颜色、背景主题、敌群顺序和数值来自所选行星，装备编排仍决定实际武器动机；本次配置没有声称为八个星球各制作了一首完整曲目。

Boss名称、生命和阶段压力随行星变化，调用现有Boss战斗系统与主程序的行星层级变化。新增八个名称不等于已经制作八套独立模型和全新AI。后续独特Boss技能应继续遵守音乐拍点、可读预警与安全缺口，而不是直接增大弹幕遮挡。

## 数据接口

- `rows()`返回八颗行星的独立元数据；`planet(id)`查询指定行星，未知ID安全回到水星。
- `route(id)`返回该行星完整波次：名称、秒数、预算、精英标记和阵形；最后一行是Boss。
- `combat(id)`返回生命、Boss生命、移速、弹速、伤害、掉落、背景颜色及主题编号。
- `kind(id, wave, ordinal)`接受从0开始的波序和普通敌人序号，返回固定、可复现的角色类型。
- `radius`、`orbit`、`seedangle`为微缩星图的显示尺寸、轨道半径和弧度起始角。`theme`与`planet_style`描述显示主题，不改变物理坐标尺度。

## 验证范围

`tests/planet_catalog_review.gd`在Godot4.7.2无界面模式通过3071项检查：八行星元数据、递增数值、全部波次、生成预算可完成性、实际阵形函数、确定性角色组成、教学门槛、未知ID回退和返回值不污染默认数据。结果在`tests/results-planet-catalog.json`。

数据与几何检查之外，本轮完成两种渲染器各37项星图检查、143项主场景整合检查，以及水星完整六波69项流程验收。其他星球尚未逐一完整通关，真人难度与听感仍待试玩。详细范围、修复和实际截图见[当版测试记录](TEST_REPORT_V4.md)。
