# 律航 V3：240件独立装备目录

共32件武器、72件改件、80件节律组件、40件生存装备、16件核心。没有以等级、品质、重复名称填充数量。相同家族的改件分别改变伤害、数量、穿透、速度、爆破和特有机制，拥有明确的适用目标。

数值为1级、未计飞船/驾驶员加成的基础值。强化等级1—4由装配系统处理，不增加物品种类。每次合成消耗另一个同类同级物品；保留所选物品、占格和位置。武器基础伤害每级增加45%，非武器规则强度每级增加35%。只有已装备物品生效，备用仓中的物品不会暗中提供属性。

价格为基础商店价。实际报价为基础价×[1+0.025×(波次−1)]后四舍五入；每店6件不同商品，至少一件武器。第1—3波的最高品质为稀有，第4—6波加入史诗，第7波起加入传奇；幸运提高已开放池内的高品质权重，不提前越过品质解锁。回收返还基础价×40%×[1+0.5×(等级−1)]，至少1星屑。刷新初始8星屑，每次递增4，下波重置。

条件按人类第1—8拍计算；同轨作用于本条8格轨道，相邻指占格边缘相接的物品；目标家族/属性必须匹配。物品占1—3格且不能跨轨，覆盖格仅计一次属性，仅起始格触发。

充能1/2/4/8表示小节数，每小节2秒，充能2首次在第2小节触发、充能8首次在第8小节触发。充能减免后向下取合法档位，至少1小节；因此8减1进入4档，而不是7档。武器自己的八音动机按实际充能发射次数推进，完整原生乐谱为64小节、128秒；移动物品同时改变发射时点与音高偏移。详见[武器音乐矩阵](WEAPON_MUSIC_MATRIX.md)。

百分比为加算小数规则，四维属性为整点；弹丸伤害倍率只应用一次，额外弹丸另行计数。装甲是属性点，实际减伤由战斗公式计算；幸运也是点数。恢复等小数收益按运行时累计，展示三位小数以保留0.008等真实值。

目录、规则校验、实际战斗与真人平衡测试是不同验收层次。该表列明内容和计算约定，运行验证结果由总测试报告记录。
