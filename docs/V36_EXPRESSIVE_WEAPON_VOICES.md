# V36：逐次发射的演奏力度与音色变化

2026-11-09，`0.36.0-expressive-weapon-voices`。按用户补充，“很弱、弱、强、很强”不仅改变分贝，还要改变演奏效果。此版为全部19件武器制作四档独立演奏样本，共76份；原152份作曲音高样本逐字节保留，总计228份。

## 发射、声音与乐句

| 有效充能 | 每次发声间隔 | 连续真实发射使用的演奏顺序 |
| --- | --- | --- |
| 1轮 | 1.5秒 | 很弱 → 弱 → 强 → 很强，循环 |
| 2轮 | 3秒 | 弱 → 强，循环 |
| 3轮 | 4.5秒 | 强 → 很强，循环 |
| 4轮 | 6秒 | 很强 → 强，循环 |
| 8轮 | 12秒 | 强 → 很强，循环 |

一轮与二轮武器每四轮完成一次共同呼吸；三轮和四轮武器加入更疏的重音。指的是跨越多轮的连续真实齐射，不能在单轮内把整组声音全部播放。每次齐射只有一声，充能等待不新增声音，尾音可以继续。力度不缩放伤害、弹数或弹体运动，也不恢复卡片下方旧拍序状态条。

音高与乐器身份固定。不同摆放格决定声音出现的时刻，同种不同UID保留独立叠奏；默认在同一全局乐句相位演奏，不随机各奏一套。编译按绝对扫描轮数和当前有效充能推导齐射序号，没有可被预览推进的运行计数器。更换配装后保持运输位置；改件改变有效充能时使用对应的新分档。

144秒重复区包含96轮，可整除全部当前力度句法与充能周期；原生回卷不重置轻重关系。12秒自然开场、1.5秒音序、0.5秒敌机行进和V35发射间隔仍适用。

## 四档不是同一WAV的四个音量

每档从既有授权GeneralUser GS音源独立离线渲染：音源力度分别为0.30、0.46、0.68、0.92，同时改变触键／弓头起音、持音和释放、低通和已有声学泛音的明暗。然后校准层间响度与逐武器平衡，最高峰值不超过0.32。钢琴、弓弦、竖琴均按各自乐器处理，没有加入鼓、萨克斯、电子叠层、移调或变速。

这些是采样乐器的四份渲染演奏，**不是四次新录制的真人演奏**。部分音源力度区共用同一底层录音，因此同时用离线包络与频谱塑形形成明确表情；不把音量归一化后的非零波形差异直接等同于主观真实或好听。

音色、源力度、持音、起音、滤波、响度与SHA见[力度源清单](../audio/instruments/DYNAMICS_MANIFEST.json)，层级与各件平衡见[统一策略](../audio/instruments/WEAPON_DYNAMICS.json)。构建命令：`python tools/build_weapon_dynamics.py`。新增76份导入资源使用无压缩PCM16，并逐项与原WAV数据核对，防止资源回退路径读到默认压缩格式。原8音高样本与原清单保留，显式作曲继续按用户谱面音高、力度和BPM演奏，不套用战斗轻重轮换。

## 核对与边界

[本轮汇总](data-v36/SUMMARY.json)记录76份PCM、152份原音高哈希、19件实际发射/音符对应、同类375毫秒重奏、原生回卷、图鉴按钮、显式作曲与背景连续播放。去掉最佳标量增益后，相邻层前150毫秒波形仍有至少18.9%的归一化残差，证明不是纯增益复制；每件四档起音RMS递增。详见[样本核对](data-v36/sample-review.json)。频谱不要求每个频带都单调增亮，音源分区与弓头也会改变谐波比例。

当前环境不能直接听音；是否好听、轻重对比是否过大，仍需用户实际试听。此轮不宣称全战役平衡或持续帧率验收。旧`composer_audio_review.gd`仍预设仅有两种历史录音武器，调用已停用的`recorded_ballistic`并越界；其失败日志单列保留，不计为现行通过项。现役作曲音符、PCM及90BPM路径由V36专项和作曲数据测试核对，生产作曲路径未修改。
