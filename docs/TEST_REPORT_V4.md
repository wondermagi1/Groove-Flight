## 八行星整合与修复

- 所有行星均可直接选择。非法ID不改变目的地，战斗中不能通过星图回调偷偷更换航线。
- 主场景发射按钮实际进入水星6波或海王星10波，原生音轨继续驱动武器。关闭星图会释放其独立3D视口；从都市返回保留角色位置。
- 接触、普通弹和预警射线均使用星球伤害。水星基础伤害1、海王星3.4，海王星危险射线6.8；护甲继续在之后结算。
- 小数掉落存在过浮点整数边界问题：地球100次普通击杀曾只有117颗、木星142颗。修复后分别为118、143；八星100次实际击杀的发放总数均通过检查。余量跨击杀保留，在新一轮出击时重置。
- 成绩按本轮实际星球记录，与正在预览的星球分开；重复完成回调不会再次计数。旧配置缺少星球字段时正常回到水星，异常条目被过滤。序列化回读使用配置文本夹具，没有冒称已人工重启玩家档案测试。
- 原两项720p边界失败来自把物理窗口尺寸与逻辑画布混用，已改为正确坐标检查。实际720p图像也已检查；视口拉伸警告、右键松开后继续旋转和返回文字不符均已修复。

当前最终渲染日志仅保留沙箱无法创建用户着色器缓存的权限提示；没有AA、SSR、视口尺寸或游戏脚本错误。

最终Godot编辑器资源导入另以正常用户权限执行，退出码0，没有脚本或导入错误，新增脚本与着色器的资源UID已生成。
