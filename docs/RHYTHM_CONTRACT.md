# 音序与音游 当前约定

2026-11-14 · V56，以[本轮重构说明](V56_MUSIC_FIRST_REFACTOR.md)、[持续维护对应表](WEAPON_VFX_AUDIO_REFERENCE.md)及[音频政策](../audio/MUSIC_FIRST_POLICY.json)为准。

1. 背景音乐为主，八星完整授权歌曲各自循环。J/K/L三键谱面来自歌曲候选点与固定指法，不由武器生成；三键合计计分，不对应装备轨的独立火力门控。
2. Perfect±35ms＝100，优秀±75ms＝80，一般±140ms＝40，Miss/长按中断＝0；长按取头/释放较差时差。错键/echo/空击不加分，同块只结一次；保留多键同时与长按，复杂组合后续开发。
3. 前6战斗秒100%弹量，之后每6秒总得分÷总满分控制下一段全武器最终弹数。允许0，仍有谱面恢复；全空段沿用，边界按尾端+140ms归段。最终数在属性/品质/精炼/驾驶员/超载之后按UID/来源轨累计小数，不额外缩放伤害/速度/射程/传导。
4. 武器原1.5秒/8格及1/2/3/4/6/8轮充能保留，独立映射音乐点自动齐射。当前琴块失误只影响下一段。武器无演奏音；实时配音、单音/录音组、预混支援/乐器/底层均停用，156秒PCM仅作无声时钟。
5. 取消流派选择/过滤，24武器混装，3+3商店、锁定/价格、品质时机保留。开局脉冲A3＋苍穹B4–B5，10点实弹基础加成保留。音色图鉴改为按弹道/充能的无配音武器图鉴，旧作曲入口退出。
6. 暂停/购物/设置/图鉴冻结BGM、时钟和计分，恢复不重播；校准±150ms/5ms，正值使谱面稍晚。换装/切波保留已结算比例，新局重置100%。不再武器触发BGM让位；其余反馈总线保留。
7. 音游面板保持音序器右侧/窄屏上移，显示歌曲、Combo、四档次数、本段总分/当前弹量和结算倒计时，四档独立颜色/文字与时差。判定线和鼠标区域共用坐标。
8. 武器独立实体运动/尾迹/射程后缩小，激光/电链形态、敌人持续运动/避让、八星任务/Boss/原生内核保持。节奏新音效、更多手势与人工难度谱面列为后续，不宣称已完成。

## 历史迭代记录

以下条目保留各版当时的约定，现行行为以上方V56规则和持续维护对应表为准。

18. 历史V27曾按用户试听要求改为2秒一轮，旧试听及验证保留在[V27记录](V27_TWO_SECOND_SEQUENCE.md)。
