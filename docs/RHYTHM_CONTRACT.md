# 音序扫描与固定武器声音：当前约定

最新确认日期：2026-11-07。用户明确将四拍强弱武器暂时搁置，以本文和V18实现为准。

1. 音序器3轨×8格，每格0.125秒、一轮1秒，白点持续循环扫描。
2. 白点到达武器的起始格时，播放一次该武器固定声音。占用的后续格不重复触发。
3. 当前武器不维护四拍强弱，不自动改变音高，也不因为摆放格不同而移调。
4. 同种武器的不同装备实例各自发声。例如两件分别占第1–2格与第3–4格，就在第1格和第3格分别响一次，相隔0.25秒；后一声允许与前一声尾音叠加。
5. 声音编译按实例UID和事件时刻混音，不能按武器种类去重，也不能用一个同类播放器截断前一件武器。
6. 保留原有充能对弹体/伤害的限制；声音每次被扫描都保持固定，不再演奏强弱周期。
7. 武器卡片下方拍序状态条移除，只保留格子扫描小白点。
8. 轨道静音、独奏和武器音量必须覆盖实际播放路径，且不影响弹体。
9. 强弱型、八音样本和原始录音保留作后续开发资料；当前不自动使用。旧四拍约定归档于 `archives/RHYTHM_CONTRACT_V17.md`，不作为当前实现要求。
10. 原有12种用户选定武器保留，用户随后确认新增武器；V21加入3种，V23再加入尾羽回响，共16种。乐器样本128份，普通战斗仍只使用固定索引0，其他音高供显式作曲。
11. 普通敌机每0.5秒推进一步，约0.22秒移动、0.28秒停顿；暂停时停止。普通机取消远程攻击，保留接触扣血，精英/Boss专属攻击保留。
12. V22按用户最新要求，敌机从我方上方、左上方、右上方出现，出生与展开路径避开玩家。当前普通批次为方阵与圆阵两类，同批同型号。圆阵先展开，近端先攻，远端沿地图绕行包围；所有单位独立运动并避让。用户对8:35圆阵的补充更新了此前“只方阵”的限制。
13. 武器实际弹数随对应主属性、品质与强化等级增加；同次触发可以分成错开的多排弹丸，声音仍只按起始格播放一次。弹数成长不恢复四拍强弱或额外声音循环。
14. V23按最新要求分类统一弹体，实弹/羽状弹幕采用鎏金基底，光束、电弧等保留对应形态。每颗实体弹的质量、初速、出膛时差和受力独立；地平线从两翼喷射，尾羽从后方形成U形羽流。有效射程内不缩小，达到射程后才进入视觉退场。
