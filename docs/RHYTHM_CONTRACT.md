# 音序扫描与武器演奏 当前约定

最新核对：2026-11-11，V54。逐武器特效、音色与试听以[持续维护对应表](WEAPON_VFX_AUDIO_REFERENCE.md)为统一入口，当前交互见[V54三轨六秒计分](V54_THREE_TRACK_SCORE.md)。

1. 音序器3轨×8格，每格0.1875秒、一轮1.5秒；充能仍为1/2/3/4/6/8轮，不因评分失败退还或重新计时。
2. J/K/L直接对应A/B/C装备轨，可改绑。只有该轨具备充能资格的武器生成琴块，仍使用当前歌曲的下一候选点；同轨同点可合并操作，不同轨同点独立判定。
3. 前6战斗秒弹量100%。此后每6秒按各轨实际得分÷理论满分，决定该轨下一段6秒的弹量。完美100、普通成功70、漏按/中断0；空段沿用上一比例，允许0%，不设额外最低火力。
4. 当前段齐射保留音乐时刻，短按类到点、长按类到尾端自动发射，与当前手势是否成功独立。单块失误只影响后段成绩，不再直接取消本发；同轨多武器保留各UID和声音。
5. 短按有效±75ms/完美±35ms；长按0.30–0.65秒及尾端75ms松手宽容保留。不同轨同时琴块不使用旧双键60ms共同门控。空击或其他轨输入不能取消本轨琴块/长按；按住与echo不授予未来分数。
6. 为保留完整宽容，计分按floor((目标尾端+0.075)/6)归段。段边界的晚按不追改已生效比例。切波/换配装/校准保留已判分和生效比例，丢弃未完成旧要求；新局才重置全部100%和小数余量。
7. 最终弹量在属性/品质/精炼/驾驶员/超载既有加成之后乘评分比例；按UID及来源轨累计不足一颗的小数，使低弹数同样达到长期比例。单弹伤害、射程、速度、激光折射和电链传导保持。
8. 仅实际非零齐射起一声原动态WAV并推进该UID力度；0弹不生成炮口、弹体、新声音或力度推进。既有弹体与自然尾音保留，不按输入成败另外补音。原生156秒PCM排除全部武器声，实时声部保留-1dB子限幅、原总线、轨道声像和同种独立重奏。
9. 力度句法保留：1轮很弱→弱→强→很强，2轮弱→强，3轮强→很强，4轮很强→强，6/8轮强→很强。固定根音，不随格子移调；288份现役WAV未替换。
10. 背景八首全曲与12+144秒PCM分别计数循环；商店/暂停/设置/编排/图鉴共同冻结背景、充能与评分，继续时不重头播放。背景静音仍有运输与谱面。校准±150ms/5ms，正值稍晚，不改变音源速度或判定宽度。
11. 自由作曲、商店和图鉴试听保持原自动/显式音符路径，不套六秒评分；轨道静音及武器总线只影响声音，不抑制弹体。设置、图鉴和教学说明须与当前规则一致。
12. 战斗琴块紧挨可见音序器右侧、底部对齐；窄屏侧边空间不足时放其右上方。显示A/J、B/K、C/L、各轨当前弹量%、已判分和下次结算时间。旧四拍状态条仍不恢复。
13. 原普通敌人每0.25秒规划并持续运动，无远程射击；上/左上/右上方阵与圆阵出生、完整机体与扫掠避让、八星任务/Boss、原生内核均保持。共振目标仍只认可圈内成功手势，自动射击不能代替演奏。
14. 实体弹独立质量、初速、出膛时差和实际受力、曲线残迹、射程后缩小保留；地平线从两翼，尾羽后方U形。分排/派生弹不额外计分或发声。

## 历史迭代记录

以下条目保留各版当时的约定，现行行为以上方V54规则和持续维护对应表为准。

16. V25按试玩反馈将武器音色统一为钢琴变化、柔奏提琴和竖琴，重制128份样本。普通战斗仍用固定索引0；每次扫描、充能分离与同种实例重奏规则保留。击杀低鼓、护盾、拾取与背景音乐属于独立反馈层。

17. V26音量按背景、武器与各反馈类别独立控制；0%真实静音。音量调整不重编PCM、不重启音序；商店、图鉴和作曲试听遵循武器音量。用户再次指定视频中的击杀低鼓、清脆拾取与28秒附近受击护盾，三者各有单独滑块；护盾素材随后按V26.1用户反馈收为28.745—28.940秒（195毫秒单次主声），后续小瞬态裁去。

18. 历史V27曾按用户试听要求改为2秒一轮，旧试听及验证保留在[V27记录](V27_TWO_SECOND_SEQUENCE.md)。

19. V31按用户最新要求仅将普通音序改为1.5秒一轮，覆盖V27。音频、白点、发射调度与商店“循环一轮”同步；充能仍按轮计算，2轮/8轮分别对应3秒/12秒。PCM缓存64轮共96秒，保证回卷与充能相位对齐。敌机仍每0.5秒推进，原音源、独立音量、背景、护盾一击与自由作曲速度不变。详见[V31试听与验证](V31_ONE_HALF_SECOND_SEQUENCE.md)。

20. V34按最新试玩反馈与用户明确选择，普通武器统一只有实际发射才发声，覆盖旧版“等待充能也发声”。全部19件核对；17种实体弹的首颗与声音同刻开始，其他颗粒保持自然错峰。音频使用12秒真实开场＋96秒重复区域，启动不混入尚未发射的尾音，回卷仍对齐。初始配装改为脉冲机炮 A3、星砂霰弹 B4、流萤织雨 C6–C8，原有非武器道具放到空位；后续波次不重置玩家编排。详见[V34说明](V34_WEAPON_AV_SYNC.md)。

实现与验证见 [V24全部武器独立运动](V24_ALL_WEAPON_MOTION.md)、[V18固定声音说明](V18_FIXED_VOICES.md)、[V23独立喷射](V23_INDIVIDUAL_WEAPON_FLIGHT.md)、[V22属性弹幕](V22_ATTRIBUTE_BARRAGES.md)及[方阵/圆阵机制](ENEMY_FORMATIONS_AND_ENCIRCLEMENT.md)。
