# 音序扫描与武器演奏：当前约定

逐武器的特效、乐器、充能与原声试听见[持续维护对应表](WEAPON_VFX_AUDIO_REFERENCE.md)。后续时序或声音修改须同步更新该表。

最新核对日期：2026-11-09。V36按最新要求启用纯音频演奏力度乐句，覆盖之前每次相同样本／相同音量的声音规则；不启用伤害四拍强弱或自动旋律。实际发射资格按V34/V35，扫描间隔按V31。

1. 音序器3轨×8格，每格0.1875秒、一轮1.5秒，白点持续循环扫描。
2. 白点到达武器的起始格且满足充能、实际发射时，播放一次当前力度档的独立演奏；充能等待轮不新增起音，已发射的尾音自然延续。占用的后续格不重复触发。
3. 当前仅音频选择力度演奏层，伤害与弹数不轮换；音高固定，不因摆放格不同而移调。
4. 同种武器的不同装备实例各自发声。例如两件分别占第1–2格与第3–4格，就在第1格和第3格分别响一次，相隔0.375秒；后一声允许与前一声尾音叠加。
5. 声音编译按实例UID和事件时刻混音，不能按武器种类去重，也不能用一个同类播放器截断前一件武器。
6. 按V35使用各武器的1/2/3/4/8轮充能；声音与发射共用资格，真实发声按有效充能使用V36乐句：1轮很弱→弱→强→很强，2轮弱→强，3轮强→很强，4轮很强→强，8轮强→很强。
7. 武器卡片下方拍序状态条移除，只保留格子扫描小白点。
8. 轨道静音、独奏和武器音量必须覆盖实际播放路径，且不影响弹体。
9. 旧伤害强弱型、八音样本和原始录音保留；新力度层只表达演奏，不自动轮换旋律。旧四拍约定归档于 `archives/RHYTHM_CONTRACT_V17.md`，不作为当前实现要求。
10. 原有12种用户选定武器保留，用户随后确认新增武器；V21加入3种，V23加入尾羽回响，V30再加入3种前向羽流，共19种。乐器样本228份：战斗76份同根音演奏层，原152份音高供显式作曲。
11. 普通敌机每0.5秒推进一步，约0.22秒移动、0.28秒停顿；暂停时停止。普通机取消远程攻击，保留接触扣血，精英/Boss专属攻击保留。
12. V22按用户最新要求，敌机从我方上方、左上方、右上方出现，出生与展开路径避开玩家。当前普通批次为方阵与圆阵两类，同批同型号。圆阵先展开，近端先攻，远端沿地图绕行包围；所有单位独立运动并避让。用户对8:35圆阵的补充更新了此前“只方阵”的限制。
13. 武器实际弹数随对应主属性、品质与强化等级增加；同次触发可以分成错开的多排弹丸，声音仍只按起始格播放一次。弹数成长不恢复四拍强弱或额外声音循环。
14. V23按最新要求分类统一弹体，实弹/羽状弹幕采用鎏金基底，光束、电弧等保留对应形态。每颗实体弹的质量、初速、出膛时差和受力独立；地平线从两翼喷射，尾羽从后方形成U形羽流。有效射程内不缩小，达到射程后才进入视觉退场。
15. V24补齐全部16种武器的个体表现：新星各弹弯转、星冕独立呼吸与惯性跟随、七彩折光匣按最新反馈改为四斜向摇摆的彩色羽状实体弹流，命中等待实际抵达；激光和电弧仍保留直束或连锁形式。各弹/束的视觉差异与分排不新增声音，V24当时未替换样本，之后的音源以最新音色约定为准。

16. V25按试玩反馈将武器音色统一为钢琴变化、柔奏提琴和竖琴，重制128份样本。普通战斗仍用固定索引0；每次扫描、充能分离与同种实例重奏规则保留。击杀低鼓、护盾、拾取与背景音乐属于独立反馈层。

17. V26音量按背景、武器与各反馈类别独立控制；0%真实静音。音量调整不重编PCM、不重启音序；商店、图鉴和作曲试听遵循武器音量。用户再次指定视频中的击杀低鼓、清脆拾取与28秒附近受击护盾，三者各有单独滑块；护盾素材随后按V26.1用户反馈收为28.745—28.940秒（195毫秒单次主声），后续小瞬态裁去。

18. 历史V27曾按用户试听要求改为2秒一轮，旧试听及验证保留在[V27记录](V27_TWO_SECOND_SEQUENCE.md)。

19. V31按用户最新要求仅将普通音序改为1.5秒一轮，覆盖V27。音频、白点、发射调度与商店“循环一轮”同步；充能仍按轮计算，2轮/8轮分别对应3秒/12秒。PCM缓存64轮共96秒，保证回卷与充能相位对齐。敌机仍每0.5秒推进，原音源、独立音量、背景、护盾一击与自由作曲速度不变。详见[V31试听与验证](V31_ONE_HALF_SECOND_SEQUENCE.md)。

20. V34按最新试玩反馈与用户明确选择，普通武器统一只有实际发射才发声，覆盖旧版“等待充能也发声”。全部19件核对；17种实体弹的首颗与声音同刻开始，其他颗粒保持自然错峰。音频使用12秒真实开场＋96秒重复区域，启动不混入尚未发射的尾音，回卷仍对齐。初始配装改为脉冲机炮 A3、星砂霰弹 B4、流萤织雨 C6–C8，原有非武器道具放到空位；后续波次不重置玩家编排。详见[V34说明](V34_WEAPON_AV_SYNC.md)。
