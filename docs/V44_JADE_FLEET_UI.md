# V44 青绿战场与精密舰体

2026-11-09，`0.44.0-jade-fleet`。修改前备份 `059ceb2ebc096766db743fcf0a0abc63f26796a1` 已上传并核验，开发分支 `codex/v44-jade-fleet-ui`。

本轮统一游戏UI、我方舰体、敌方舰体与战场配色。采用现有程序几何和批量网格继续细化，不新增外部绘画/3D依赖。参考 `E:/安泊尔57天王.mp4` 的战场颜色，未复制视频画面或将参考素材用作游戏贴图。

| 六组UI | 主界面/HUD/设置、商店/音序工坊、机库、星图、音色图鉴、自由作曲共享深青绿面板、暖白文字、青灰次级信息、暖金分节标记。压低大圆角，保留属性和品质的语义颜色。 |

| 战场 | 墨绿至青绿的低频雾面和纵深，保留远景行星纹理/光照细节。原背景单pass里增加至多两层低频噪声与轻微暗角，不新增全屏模糊、灯光节点或阴影pass。背景亮度、画质和原运动参数继续生效。 |

参考视频在4:10、7:18、8:35、10:10各取一帧，分析中央战场，排除UI、亮弹和黑边。后三帧背景中位RGB约为28/80/69、23/84/74、25/83/75；较亮4:10为52/102/96。当前生产背景端点为 `#082e28` / `#2d8276`，实际1920×1080截图同类区域中位约21/72/65，20–80分位17/63/56至32/93/85，作为略暗的游戏底色衬托装甲与彩色弹幕。这是颜色取样，不是整段视频画面或音频分析。

主要/次级文字与面板的静态对比度分别约13.12:1和6.79:1。1080p与720p、商店120%文字检查六件商品锁定按钮仍与图示分离；战前流派选择、左下角音序器与恢复入口、背景音乐连续播放仍保留。

本轮保留V43流派和初始配置，24件武器参数、288份音源、音序器/敌机节奏、实际弹道、敌群路径/净空/碰撞、原生crowd内核及数值不变。详见[逐文件资产核对](data-v44/asset-preservation.json)及[当前验证](data-v44/SUMMARY.json)。
