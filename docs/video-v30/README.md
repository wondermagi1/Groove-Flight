# Four forward feather patterns

`forward-feathers.mp4` is a controlled Godot MovieMaker visual capture, not a
campaign or FPS recording. Four4second sections: beam_split,dawn_fan,
tidal_weave,firefly_rain. Level4,primary attributes32,no enemies,muted runtime
audio. Original496frames/30fps (16.533s),1600×900. Startup/cleanup frames are
included. Weapon direction is hull-forward.

The soundtrack is assembled offline from the same four `inst_*_0.wav` runtime
samples, one note per2seconds. No extra note is attached to individual rows.
No backing music/feedback is mixed into this audition. A separate production
renderer ensemble is under `docs/audio-v30/native-forward-ensemble.wav`.

Recorded with `tests/v30_forward_feathers_review.gd --capture-feathers`,
`--write-movie work/v30-feathers.avi --fixed-fps30`, then H.264/AAC MP4 encoding.
See `docs/V30_FORWARD_FEATHERS.md` and the living VFX/audio registry.
