# V72 音游打击与齐射反馈

2026-11-22 · `0.72.0-rhythm-impact` · 修改前远端备份 `af3b3763f6a7a7ebc32f274174ea7ec4168623bf`

## 已实装

- 八星齐射统一等待充能后的首个音乐手势收尾。短按、双押在落点，长按、连打在尾端。手势仍可打出不同等级，自动发射的强弱由六秒合计成绩决定。八首歌的原谱、分段曲速、水星留白与基础弹量下限继续生效。
- 时差显示在 ±45 毫秒内的 Perfect 触发白色打击闪光，并提高当次已有击键音的混音优先感。增加的音量最多 1.2 dB，由原音游总线限幅，提前按中的普通触点依然只响一次。判定仍是 ±150／200／250 毫秒，对应 100／80／40 分。
- 右下角显示临近齐射的刻度。实际有弹发出时，弹量读数和战机两侧同步亮起，奖励弹量超过 100% 时用金色。一次齐射和同拍重奏共享短暂的视觉反馈。战机两侧在减少特效模式下使用较短、较轻的线条。
- 从 5 连击起播放里程碑提示。Perfect 奖励菱标的亮度显示离下一档的距离。每六秒短显基础弹量的实际涨跌，以百分点计。休止段延用上一段基础火力。

后续可把曲目的副歌、低音进入和 Boss 露核安排成短段目标，让乐句与战斗阶段共同形成高潮。现阶段各曲的既有任务、敌人机制和配装数值照常运行。
