# V52 · 画面与界面协调

2026-11-11，`0.52.0-ui-harmony`。修改前已上传并核验备份`c22af8bd6b7b3cfc90fb9129ebf0d5cc45bbc635`，开发分支`codex/ui-harmony`。

界面采用黑灰面板、白色正文、灰色次级说明与少量淡金交互提示。颜色留给武器弹幕、品质、属性、流派和舰体身份；没有恢复之前被否定的青绿色战场或V44皮肤。战斗顶部继续透明、白字描边，倒计时保持56px上限和粗体。

## 实际修改

- 四键面板移除整片白色轨道，改为深色半透明框、细分隔线、象牙白琴块和底部琴键。长按用细长身体连接头尾，双键保留连线；按住/通过用淡金，失败用淡红。位置仍在右下，装备音序器在左下。
- 统一`ui_materials.gd`的字体、黑灰材质、细边框、圆角、普通按钮、滚动条、音量滑杆和输入框。接入主菜单、设置、商店/工坊、机库、星图、图鉴和作曲界面。深色结构材质去除蓝青偏色，明亮的语义颜色保留。
- 顶部超载信息移到生命下方，经济信息独立靠右；通知与Boss说明分行排布，避免小分辨率下互相挤压。波次缩为简洁星球/编号，教学提示放到独立区域。
- 图鉴的普通说明改为中性灰白，试听按钮统一材质，并明确“试听间隔”与“实战完成琴块后演奏”的区别。作曲卷帘的背景/网格去蓝，声部音符仍按武器颜色区分。
- 界面离开场景树后停止刷新，避免关闭图鉴/退出场景期间重新创建控件。

这些改动只涉及呈现。V51的H/J/K/L、短按/长按/双键、判定窗、充能资格、歌曲位置、独立重奏和失败取消保持。琴块绘制与鼠标命中使用同一轨道顶部和行程；白色头部周围保留少量点击宽容。没有修改实际战斗、背景着色器、敌我机体、弹数/伤害/弹道、288份现役WAV或原生DLL，也没有重打包旧Demo或覆盖用户PPT。
