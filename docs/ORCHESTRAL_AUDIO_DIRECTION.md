# 后续乐器组开发总体框架

2026-11-09，用户确认的后续方向。当前V38已实现一秒武器演奏、流萤彩虹和十种长充能发射编排；本文记录未来配器，**不表示新乐器已接入**。

## 用户最新确认的统一乐器组

| 组别 | 乐器 | 建议职责 |
| --- | --- | --- |
| 键盘，1种 | 钢琴 | 清晰起音、短句和节奏 |
| 弦乐，4种 | 小提琴、中提琴、大提琴、低音提琴 | 高中低音主体、应答和层次 |
| 拨弦，1种 | 竖琴 | 流动、分解音与起音点缀 |
| 木管，4种 | 长笛、单簧管、双簧管、巴松 | 旋律与应答；双簧管偏独奏句，巴松偏中低音性格 |
| 打击乐，3种 | 三角铁、钟琴、定音鼓 | 少量明亮点缀与有音高的低频重音 |

共13种，作为后续音源、力度与演奏法、武器声部及整体混音的统一开发框架。用户最新合并清单覆盖此前A/B方案的组织方式；不设定A固定用于常规战斗、B固定用于Boss的规则。此前提及的圆号不计入本次13种核心清单，是否扩展留待后续决定。

实施顺序建议：先建立有授权来源、音区和演奏力度差异的音源库，再逐件分配武器，最后核对叠奏与整体混音。框架代表可用的乐器资源，各武器根据定位选择主声部与陪衬。

## 后续分配建议

- 钢琴、竖琴负责清晰起音、短句与流动；弦乐按音区分配主体、应答与一秒重音。
- 长笛、单簧管承担少量旋律/应答声部；双簧管用于突出独奏句，巴松用于中低音性格。
- 三角铁、钟琴用于少量点缀，避免每次齐射都堆叠高频装饰。
- 定音鼓承担有音高的低频重音。武器重音与独立击杀低鼓通过音区、起音和长度区分。
- 先用少数代表武器比较，再逐件分配。每件保留独立音色身份，避免所有乐器在同一触发时刻争抢主声部。

## 继续遵循的实现约定

新增乐器需明确授权来源、对应武器、实际样本与四档演奏差异，并更新[持续维护对应表](WEAPON_VFX_AUDIO_REFERENCE.md)。当前十件三四轮武器的一秒资源要求仍有效；保持固定根音、实际发射才发声、同种独立叠奏和一次齐射一声，声部组合可预先合成在同次演奏里，不能按子弹数/弹排重复触发。武器声部继续走独立武器音量，击杀/护盾/拾取/背景仍分别控制。

历史V25曾限制武器只有钢琴、弓弦和竖琴。用户本次明确允许未来按统一13种框架扩展长笛、单簧管、双簧管、巴松、低音提琴、三角铁、钟琴、定音鼓；该方向用于后续开发，不应提前把当前素材清单标记为已经包含它们。
