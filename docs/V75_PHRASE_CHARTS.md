# 八星三键谱与读谱美术

2026-11-23 · V75

每首歌写了各自的八拍主题、答句和副句。开头用半拍速介绍主题，随后以八拍为单位回应、变形、收束。每四小节测量一次原曲相对响度，响度较高的乐段使用副句。金星的答句在中键附近回旋，地球让三键依次上行和下行，火星让两侧交替应答，海王星用中键衔接快速换向。这是一套依据波形生成、结合人工指法的游戏编排。

切分只替换已有的普通弱拍。生成时在半拍或四分之一拍附近寻找真实起音，相邻手势须各留至少 335 毫秒的原曲时间。长音依据发音主体与尾段的能量比调整长度，并给下个琴块留出空间。每个键单独预留至少 300 毫秒的原曲换指时间，最高 1.18 倍曲速时约为 254 毫秒。连打的两次不同键触击保留各曲原有间距。

右下角仍是三条等宽琴轨。行星色用于轨道玻璃与键框，常规琴块保持高亮。小节在两侧刻短线，每八拍的句首先加折角。切分用双斜刻纹，双押用同高双线，连打用带箭头的弧线，末键留有圆点。降低特效后这些读谱标记仍可见。[火星谱道实机画面](data-v75/mars-board.png)
