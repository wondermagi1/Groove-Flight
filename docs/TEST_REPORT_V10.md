## 画面验证

已查看Forward+的32件武器放大渲染图，比较了武器实体、切面、刃形、轨道结构与焰流；查看过光束、电弧、炮口、命中、冲击波图和正式战斗场景调用截图。读取GPU实际图像检查所有武器均可见，32个裁剪区域得到不同像素结果。像素不同不等于32件独立美术模型：它们是12类共享着色轮廓和型号细节、比例的变化。

正式场景展示同时调用32种武器，并手动推进固定时间，产生109个弹体，全部进入新渲染批次；高生命固定目标用于捕捉命中和光束。未把这个展示声称为真人自然游玩。

## 性能范围

在1920×1080展示场景中，对1200个弹体持续重建实例变换与颜色，35帧短样本：

| 渲染器 | 帧间隔中位数 | P95 |
| --- | ---: | ---: |
| OpenGL |8.174ms|8.776ms|
| Forward+ |7.722ms|8.327ms|

样本包括实例更新和渲染，未同时进行图片编码；不包括完整640敌人AI、空间查询、碰撞与音乐压力，不是GPU耗时标定、整局FPS承诺或低端设备保证。普通物理行为由100项战斗夹具另行验证。

真实短试飞的音符攻击最大时差约5.77ms；持续光束仍随note-off停止。音乐合成和声音资源没有改动。数字限流、光晕密度控制只影响画面，不限制伤害。
