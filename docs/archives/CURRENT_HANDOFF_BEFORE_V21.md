## 当前规则与历史说明的区别

1. 生产配装 `configure_live_rules()` 当前启用3轨；电子武器已恢复，录音武器由 `RECORDED_WEAPONS_ENABLED=false` 隐藏。
2. 电子武器走 `_schedule_single_shot()`：音序每格0.125秒、8格一轮1秒；白点到达武器格时只触发一次，不使用强弱比例。
3. 生产分支将普通武器事件的 `repeat` 和拍序派生置零，另保留驾驶员 echo 特例。
4. `_play_recorded_weapon_group()` 按6个录音品质条目持有独立播放器，同一原型的品质档共用同一原声组。实弹连奏炮使用一个完整16秒周期；战斗事件仍按1秒推进本地四拍，连续录音内部事件与弹道的逐拍对应仍是下一轮真人试听重点。
5. `music.gd` 的程序伴奏和 groove 数组为空，设置中的底层伴奏/节拍鼓组滑杆已移除。敌机命中的低频重击与玩家护盾来自 `events_enemy_collision` 的授权撞击/护盾段。
6. `planet_music` 不再检查星球ID；水星到海王星的战斗、暂停恢复、编辑器和波间商店都循环同一份20秒关卡BGM。
5. 音频处理继续遵循 `AUDIO_PIPELINE.md`：入库、完整提取、全段分析、确认事件/周期、截取、映射、验证。四段现有原声组的直接播放规则应保留，任何切分、变调或时间拉伸方案都要单独讨论，不能为修复节拍而自行改变素材规则。
