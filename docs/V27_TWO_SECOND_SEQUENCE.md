# V27：2秒一轮音序试听

2026-11-08，`0.27.0-two-second-sequencer`。按用户要求，普通战斗音序器当前改为**3轨×8格，每格0.25秒，一轮2秒**。

| 项目 | 当前行为 |
| --- | --- |
| 白点扫描 | 0、0.25、0.50……1.75秒依次经过8格，2秒回到第一格 |
| 固定武器声音 | 每次经过起始格播放一次，间隔2秒；声音文件的音高与长度不变 |
| 同种武器重奏 | 第1格和第3格各自发声，间隔由0.25秒变为0.5秒 |
| 充能 | 保留原充能轮数；2轮武器每4秒发射，8轮武器每16秒发射，等待充能时仍有固定扫描声音 |
| 商店试射 | 声音、发射与白点共用相同节奏，“循环一轮”在2秒处重播 |
| 独立规则 | 敌机每0.5秒推进、生成检查节奏、击杀短鼓列、背景音乐文件与自由作曲自有速度保留 |

这次调整仅用于当前2秒循环试听方向；没有恢复四拍强弱、自动旋律或按弹排加声音。每种武器的单次发射数量、弹道和音源保持原样。循环变慢后，按轮计的发射与改件事件也随之变慢。

[8秒音序试听](audio-v27/two-second-sequence.wav)：由生产音乐渲染器重新生成，共4轮，使用受控9模块钢琴/提琴/竖琴配装，含两件同种钢琴。关闭背景与反馈，便于听扫描间隔；并非把旧录音放慢。

生产时钟共用`arsenal_loadout.gd`中的0.25秒格长；`music.gd`、音频事件、白点和试射读取相同规则。提升音频缓存版本，避免沿用旧1秒节奏的缓存。

验证覆盖16种武器的声音与充能间隔、同种实例0.5秒错开、三轨白点在2秒回卷、原生音频驱动的连续发射及暂停恢复；自由作曲和分类音量另做兼容回归。结果见[data-v27/SUMMARY.json](data-v27/SUMMARY.json)。
