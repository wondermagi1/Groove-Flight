# V60 · 赛博光路与简洁界面

2026-11-17 · `0.60.0-cyberpunk` / `codex/cyberpunk-interface`。修改前远程备份 `2e5f29d` 已上传并验证。用户要求整体从写实太空转向赛博朋克，UI简洁、字体分工，并删除超载。

## 当前表现

战斗与主页使用原创 `cyber_battlefield.gdshader`：深黑底、紫/洋红/电蓝光路、分面城市板块、断开的轨道环和稀疏信标。八星保留不同色调/位置，背景明暗与三级画质继续生效。活动背景没有摄影贴图采样；旧有授权贴图与原着色器作为历史素材保留。航图使用同方向的程序化星球光路与紫色土星环。

共用UI为近黑色、轻紫灰边、3px小圆角与白字，菜单/机库/图鉴/航图/设置继承同一结构。战斗顶部依旧透明白字，去掉原超载一行。增益空态与设置说明缩短，详细武器机制继续按需展开。

字体按功能分配：Oxanium几何标题、JetBrains Mono等宽数值/倒计时/Combo、系统中文正文。中文标题优先等线再回退雅黑/Noto，完整汉字保持可读；不分发Windows字体文件。两套新增字体使用SIL OFL1.1，原文件未修改，[来源/哈希](../assets/fonts/SOURCES.json)、[许可](../assets/fonts/README.md)随源码与未来导出携带。

敌我飞机采用偏紫的冷白装甲、硬朗明暗面与发光核心。八类敌机仍共享原来的单个批绘网格，不增加逐敌节点/灯光/碰撞体。

## 音游

保留[V59](V59_RHYTHM_ART.md)完成的右下角高轨道：宽224–280，高330–540，距右下18px；1080p为260×475，720p为224×330。音符12px，底键32px，下落区238–448px。

短按是冷白切角光条，长按是金色光带和尾标，同时点用紫色连接；有效长按头固定在判定线上。命中短暂显示光环/棱片，低特效关闭装饰流光与颗粒，常驻仅键位、Combo、弹量百分比。预读仍2.2秒/Echo2.8秒；加高改善音符空间分离，不扩大判定窗口。无介绍段落与公式。

## 超载已移除

删除E动作及旧存档映射、击杀充能、充能状态、主动释放、回血/清弹/范围伤害、持续期间额外2发/1.75倍伤害、玩家光圈、HUD条、设置按键及教学/结算描述。Boss核心暴露仍是原来的独立机制。

五个相关道具同步清理充能效果：鼓点燃料罐、生命蓄电池、医疗换能器、雷暴跃迁核保留各自其余有效规则；再启动发电机原来只有充能，改为每秒恢复0.06生命。内部旧`c_overload`物品ID为兼容保留，其内容仅冲刺导弹和动力代价。没有隐藏超载通道。

24武器的基础伤害、基础数量、充能、弹道、光晕/尾迹与成长定义未改。弹量继续由六秒三键成绩及Perfect奖励控制；背景音乐优先，武器仍无配音。八首完整歌曲/3487音乐点、任务、普通敌机行进与原生DLL保持原样。
