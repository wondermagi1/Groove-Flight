# 自由作曲：乐谱与MIDI数据

此模块保存可编辑音符，不把音高绑定到武器的预设八音动机。武器在这里是声部的音色和战斗表现；旋律、时值、力度、休止和和弦由乐谱决定。

本版内置《星港练习曲》作为原创操作示例，没有内置《发如雪》的曲谱或录音。用户准备的MIDI可以导入后编辑，再映射为武器声部。

## 乐谱单位与限制

- 速度40—240 BPM，四拍一小节，最小网格为十六分音符，即四分之一拍。
- 1—8个声部，每声部可选择目录中的任一武器。允许同一位置的多音和弦、跨拍延音、空拍、独立音量与声像。
- 音高使用绝对MIDI编号24—108，即C1—C8。十二个半音均可编辑；不限制为C小调。
- 乐谱1—256小节，单曲最多10分钟、8192个音符。较慢的速度会先达到10分钟上限，不能据此推断任意速度都支持256小节。
- 缩短小节数若会切掉现有音符，操作会被拒绝。删除尾部音符后才可缩短。
- 所有音符有唯一正整数ID。删除或改音符不会改变其他音符身份。失败的操作和文件导入不修改当前乐谱。

播放侧还会限制实际合成工作量，避免大量超长重叠音符耗尽资源。该音频预算与这里的数据容量是两个独立限制，由播放器说明和错误反馈呈现。

## JSON格式

```json
{
  "format": "beatdrift-score",
  "version": 1,
  "title": "我的乐曲",
  "bpm": 120.0,
  "bars": 8,
  "tracks": [{
    "id": 1,
    "name": "主旋律",
    "weapon": "pulse",
    "role": "lead",
    "volume": 0.8,
    "pan": 0.0,
    "mute": false,
    "solo": false,
    "notes": [{"id": 1, "beat": 0.0, "duration": 1.0, "pitch": 60, "velocity": 90}]
  }]
}
```

可选`role`默认为`auto`，允许lead/bass/harmony/pad/accent/kick/snare/hat；旧V1文件兼容。鼓组按职责合成非定音打击声，普通轨的绝对MIDI音高保持不变。

`beat`和`duration`均以四分音符的拍数计，不是秒。声像-1为左、+1为右；力度1—127。静音优先于独奏；启用独奏后仅有独奏且未静音、音量非零的声部进入事件安排。低音或和弦同样是完整的可编辑音符，不是自动附加的固定背景。

JSON保存使用同目录唯一临时文件，写入、刷新成功后再替换目标。写入或替换失败会保留原文件并返回错误。读取上限4MB，必要字段、范围、ID、乐器和网格都经过校验；无效JSON不会清空正在编辑的作品。

## MIDI导入与导出

支持标准MIDI文件SMF格式0和1、PPQN按拍计时。实现音符开/关、NoteOn力度0关闭、运行状态、同拍和弦、力度、多通道和CC64延音踏板。音轨名称保留，普通General MIDI程序号映射为可用武器音色，导入后可以自由改换。

导入规则与反馈：

- 最大文件8MB，输入最多64个MIDI音轨、100000个事件；最终最多8个声部和8192音符。
- 第10通道打击乐按GM音高分为kick/snare/hat，保留音符；导出时使用第10通道。C1—C8以外的音符仍跳过并提示。
- 音符起点和长度量化到十六分网格，过短音符至少占一格；有变化时明确提示。三连音、摇摆微时差和装饰音可能改变。
- 本版采用文件最早的速度，缺少速度事件时使用120 BPM。发现不同速度的变速段会说明将统一播放，不声称完整保留原速度曲线。
- 非4/4拍号按四拍一小节显示，提示拍号差异；音符的拍数保留。
- 未闭合的音符在轨道末尾关闭并提示；SMPTE时间码、格式2和损坏文件返回可读错误。
- 导入过长、过慢或过密而超过本版容量的文件会被拒绝，当前作品保持原样。超过8个声部按音乐职责合并并提示，保留全部音符；混音重新平衡，静音/独奏标记保留。若组合仍超过8轨则拒绝导入。

导出为格式1 MIDI：独立速度轨及各声部，音符按起点与关闭时点排序，关闭事件在相同时间的新音符之前；尾部空小节保留。导出也使用同目录临时文件后替换。标准MIDI携带音高、拍长、力度和速度；本程序另在可选的sequencer-specific元事件中写入`BEATDRIFT1`混音与武器标记，供本程序再次导入时恢复。其他音乐软件可以忽略这个元事件，并用自身乐器演奏音符。完整工程状态仍建议保存为JSON。

## 程序接口

`composer_score.gd`继承RefCounted，`new()`生成原创示例，`empty()`建立一轨空作品。

| 接口 | 结果 |
| --- | --- |
| arrange(accompany=false) | 原音符不变的重新配器；可选新增伴奏，返回音符/声部统计 |
| reset_demo / empty | 重建原创示例 / 空作品 |
| add_track(weapon,name) / remove_track(index) | 新增返回轨索引或-1；删除返回bool，不能删最后一轨 |
| add_note(track,beat,pitch,duration,velocity) | 返回唯一音符ID或-1 |
| find_note(track,id) / remove_note(track,id) | 当前音符字典 / 删除结果 |
| change_note(track,id,changes) | 原子修改位置、音高、时值和力度 |
| set_bpm / set_bars | 校验速度、容量和是否截断后返回bool |
| validate | `{ok, errors}` |
| to_dict / from_dict | 规范化深拷贝快照 / 校验后原子替换，返回`{ok,error}` |
| save_json / load_json | 实际文件保存、读取，返回`{ok,error}` |
| import_midi / export_midi | 返回`{ok,error}`，导入可额外包含`warnings` |
| duration_seconds / step_seconds / step_count | 曲长、单步秒数、小节×16 |
| schedule(serial) / all_events | 指定循环步事件 / 单次乐谱所有可听事件 |

`schedule`和`all_events`共享事件构造器，查询不会推进任何隐藏计数。事件携带音符ID、武器ID、绝对MIDI音高、力度、秒时值、声部、音量、声像、拍位置和步编号。整曲安排只需遍历音符再排序，音频合成无需反复扫描每一步的全部8192个音符。播放线程可以读取深拷贝快照，避免修改正在编辑的数据。
