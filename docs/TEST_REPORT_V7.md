# 律航 V7 · 行星背景与机械巨构

2026-10-30，Windows、Godot4.7.2、RTX4060 Laptop。测试使用`--beatdrift-test`，不写玩家设置与星球成绩。

## 本次实现

八条航线使用独立的球面表面、大气边缘、云层/地形与构图。水星撞击坑、金星暖色云层、地球海陆云带、火星赤砂峡谷、木星巨斑、土星光环、天王星冰青细环、海王星深蓝风暴分别对应选中的航线。背景随飞行位置轻微视差，不用全屏黑白闪烁表现节拍。

Boss统一使用“星球名＋机器”，星图、波次与战斗血条读取同一目录。机体采用填充装甲、舱段、铆钉、炮座、散热口、机械虹膜和主题附肢。主体半径由82扩大到158—214世界像素，轮廓进一步伸展；并非3D建模或图片资源，而是本项目程序绘制的2D机械美术。

入场沿音乐时间缓慢接近，前2.4秒不开火；半血时核心装甲展开、散热边缘亮起，播放机械提示音。重炮保留音乐时钟上的预警，环形弹从主体装甲边缘出现。主装甲与核心使用相同的圆形命中区域，外围轨道/炮组属于装饰附肢。Boss生命、伤害与波次没有提高；命中面积扩大，不能据此宣称难度与旧版完全相同。
