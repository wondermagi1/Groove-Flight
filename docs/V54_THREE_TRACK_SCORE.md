# V54 三条武器轨的六秒计分

2026-11-11 · `0.54.0-three-track-score` · `codex/three-track-rhythm`。
修改前已上传并核验备份`4325c6acc2be845634c32f874ddbe134eb94ceb4`，分支`codex/backup-20261111-before-three-track-rhythm`。本版落实用户确认的“三轨分别计算：J→A、K→B、L→C”。

## 当前规则

三列琴块与A/B/C装备轨一一对应，可在设置改绑。歌曲继续提供原来的音乐时刻和长按长度，实际装备在哪一轨就生成在哪一列。同一轨、同一音乐点的多个武器共用一个琴块，各自弹数和声音独立；不同轨同点时各自判定，漏掉B不会取消A。没有武器资格的音乐候选点不强行刷操作要求。

每个战斗6秒单独结算每条轨：**该段实际得分÷该段理论满分，成为这条轨下一段6秒的弹量比例**。前三轨开局0至6秒都是100%。该轨本段没有可计分琴块时沿用上一比例，不把空段算成0%。商店不限时，暂停/设置/编排/图鉴均冻结战斗运输和六秒计时。

| 输入结果 | 得分 | 判定 |
| --- | ---: | --- |
| 完美 | 100 | 误差不超过±35ms |
| 普通成功 | 70 | 超过35ms但不超过±75ms |
| 漏按或长按中断 | 0 | 超出有效窗口、未完成长按或失焦中断 |

长按头部仍需通过，尾端前75ms内松开也可通过，继续按住到尾端同样通过；最终分档取头尾中较大的有效偏差。按住/键盘echo不会自动给后面的琴块计分。不同轨的同时琴块按各自时间窗口计分，不再使用旧四键的双键60ms共同授权条件。空击不提供分数，不会取消其他轨道的琴块。

例如A轨一段中有4个琴块：两个完美、一个普通成功、一个漏按，得到270/400分，下一段A轨弹量67.5%；B和C按各自成绩计算。当前段单次失误不再立即取消当次攻击，这是对V50至V53门控方式的明确替换。

## 发射与声音

武器保留原1.5秒音序、1/2/3/4/6/8轮充能资格及映射后的音乐点；短按类在音乐点自动齐射，长按类仍按原谱面尾端齐射，与玩家这一次是否按中独立。按中只改变成绩，避免输入事件再次发出同一齐射。

弹量先按既有属性、品质、精炼和驾驶员/超载加成算完整数量，再乘该轨当前生效比例。每个武器UID与来源轨分别累计不足一颗的小数：满额1发且比例50%时，会在连续机会间累计形成实际1发，不会一直舍入成0或一直强制保留1发。每次实际数量不超过原满额，长期总量符合比例，单弹伤害不变。

激光的束数、电链的起始分支数也走原`count`数量轴；既有折射/传导规则、单段伤害不因该分数再乘一次。0%表示没有本段新武器弹体、炮口、武器音或力度推进，已发出的弹体及声音尾音保留。琴块在0%时继续生成，下一段可凭演奏恢复火力。没有额外30%之类的最低火力保底。

每次实际弹数大于0的齐射仍只发一次原动态WAV，同种多个实例独立重奏；分排/分叉不增加起音。原生156秒PCM继续排除武器声，实时声音来自实际非零齐射，受原武器总线/限幅/声像控制。自由作曲、图鉴和商店试听保留原自动或显式演奏，不套六秒弹量。

## 边界和状态

为保留完整75ms判定宽容，琴块按`floor((尾端目标时间+0.075)/6)`归计分段。譬如目标5.98秒的短按可以晚到6.04秒，它属于第二计分段，不能在6秒时提前判为失败并修改已经生效的比例。长按跨段同理。这是段边界的归属规则，没有把判定窗口缩窄。

切波、购物、重新编排和校准保留已结算比例及已判分；换配装丢弃尚未完成的旧输入要求，不补判未来琴块。只有新开一局重置开场100%及所有小数余量。校准仍为±150ms/5ms一步，并保持背景进度。输入列B的空击不会打断A的长按。

主要路径：`scripts/rhythm_score.gd`负责计分段和小数弹量；`rhythm_gate.gd`分别处理判分与自动音乐齐射；`main.gd`在发射前应用最终弹量；`rhythm_tiles.gd`显示三列名称、当前比例、已判分和结算倒计时，面板紧挨可见音序器右侧并底部对齐；窄屏侧边空间不足时放在其右上方，避免遮挡配装。谱面schema3在`audio/charts/planets/`，保留3487个候选点的原时间/长按数据，移除旧四键随机列和人工双键。
