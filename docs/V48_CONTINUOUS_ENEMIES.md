# V48 持续行进与早期高品质商店

2026-11-10，`0.48.0-continuous-enemies`。修改前备份`b9e7f95ea6a8c1b58a8f8cb0bbbd9ad70f16acb0`，商店调整前备份`b1d214c2762c654c467e4516804103f25117ba58`，均已上传核验。开发分支`codex/continuous-enemies-early-quality`。

## 普通敌机持续移动

取消V47的每步0.16秒移动/0.09秒停顿，以及每个规划段末尾的三次缓出减速。普通敌机在完整0.25秒规划区间内持续前进，不再按固定节奏冲一下停一下。平均速度保持V47设定：基础速度×1.20；八种普通机之间的速度差异、每秒1弧度转向上限和外围包围速度倍率保留。

路线与局部避让仍每0.25秒重新求解，实际位置每帧沿安全线段插值。下一段从上一段在边界时刻应达到的终点出发，不把渲染帧遗漏的末尾位移丢掉，也不在规划边界产生固定停一帧。矩阵前瞻和包围目标使用同一个规划起点和固定边界时间，避免在低帧率下叠加多余位移。

规划阶段不覆盖上一帧实际位置；`main.gd`原有接触扫掠因此可以检查上一段剩余路径和当前路径。所有敌机共用线性时间参数，保留原生避让内核已经求解的相对扫掠约束。C++、DLL和`.gdextension`未改动，脚本后备使用相同计划。

矩阵仍平滑展开约3秒，圆阵先径向展开，随后近处进攻、远处绕行包围。出生净空、个体完整性和视野外路线保留。局部拥堵或障碍前仍允许减速/等待；“持续”取消固定冲停，不要求穿过其他机身。暂停与设置界面冻结音乐时间时，敌机也保持冻结。精英和Boss行为不变。

## 商店品质提前解锁

原武器品质上限跟随道具曲线：史诗第4波、传奇第7波；现将武器上限单独提前：

| 商店标注波次 | 可刷武器品质 |
| --- | --- |
| 第1波 | 普通、稀有 |
| 第2波 | 普通、稀有、史诗 |
| 第3波及之后 | 普通、稀有、史诗、传奇 |

这是允许进入随机池，不保证每次都有高品质。初次补给和保留锁定后的刷新共用规则；锁定位置与原价、同店不重复、流派限定、3件武器+3件道具、幸运/构筑倾向和原价格公式保留。非武器道具的品质曲线仍按第1/4/7波解锁。激光/闪电的小武器池仍可为凑齐3件不同武器单独提前提高武器上限，沿用V43例外。实弹流第3、4波未持有西风时的初次补给保证不变。

实弹开局10点、波末两项实弹/一项通用、+3/+5/+7/+10与一次性倍率规则保留。24种武器的基础伤害、弹数、充能、物理弹道、音源和1.5秒音序器均未修改。V46展示PPT与图片也保留原文件。

## 验证

- 在30/60/120/144Hz、原生/脚本后备、完整批次/直接生成两种路径下，单个自由追击单位每帧都有位移；跨边界没有固定停顿。基础速度142的样本四秒行进约681.60单位，与V47平均速度一致。
- 不规则帧间隔、暂停冻结、出生对拍、规划不覆盖旧位置、跨规划段的玩家接触扫掠均通过。
- 600架15秒矩阵及144架52.5秒圆阵通过净空和包围检查。600架出场3秒时面积约为初始9.09倍，没有原地滞留单位；15秒末仅1架局部等待，600架均移动超过20单位。
- 1500组初次商店、200组真实锁定刷新验证第2波史诗、第3波传奇确实可出现，同时保留低品质、价格、配额、唯一性和道具曲线；V43流派与全锁定组合回归另行保留。
- 1920×1080 Forward+、1024架和八件Lv.4武器的两段各16秒测试保持全部敌机与武器，无普通机远程弹和末尾待发弹积压。帧耗时P95约21.73/22.33毫秒，最大31.01/29.79毫秒；仍有渲染帧耗时峰值，不能据此承诺整局持续60FPS。
