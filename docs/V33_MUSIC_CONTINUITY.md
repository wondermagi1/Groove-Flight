# V33：调节声音保留背景音乐进度

2026-11-09，`0.33.0-music-continuity`。修复局内暂停后进入设置、调节声音并返回时，Filaments从头播放的问题。

原生复现中，背景在91.16秒暂停后，`playing`返回false，但`has_stream_playback()`仍为true。原状态同步每次把暂停误判为尚未播放，调用`play()`重置到开头。现在只在确实没有播放实例时启动背景，保留暂停位置；离开战斗则停止旧实例，包括暂停中的实例。

音量滑块、0%静音、恢复音量和恢复默认继续直接作用于各类音频通道。背景在暂停/配装页保持暂停，回到战斗从原位置继续；直接从战斗或商店进入设置时维持既有的背景播放行为，调节不会回卷。菜单设置也保留菜单曲进度。

武器样本、背景文件、分类音量、1.5秒音序、半秒敌机，以及流萤织雨 A3–A5/七彩折光匣 B7–B8初始配装保留。

[验证汇总](data-v33/SUMMARY.json)保存相同原生专项的[修复前失败记录](data-v33/results-before-fix.json)和[修复后通过记录](data-v33/results-v33-music-continuity.json)。测试将真实Filaments跳至91秒，覆盖8类真实滑块各3档（含0%）、恢复默认、暂停/继续、直接战斗设置、商店、编辑器与菜单；另跑分类音量回归。该专项核对播放位置和状态，不代替真人混音验收。
