## 本机测量

音频专项的1小节谱例准备约40.02ms；原生音符回调最大拍点差约2.66ms。最终整合流程使用90BPM、2小节、6个半音/和弦音符，记录最大差约3.64ms，并导出470444字节的有效RIFF WAV。均为短谱例测量，不是10分钟满容量性能承诺，也不是人耳端到端延迟标定。

编辑器完整导入成功，新增脚本UID已生成，没有GDScript解析或运行异常。受限环境日志包含系统证书库读取失败，整合运行另有一次OpenGL着色器磁盘缓存写入失败；这些引擎环境信息不计作应用用例通过依据，也没有用于联网功能。
