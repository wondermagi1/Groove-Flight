# V18 固定武器声音与筛选阶段

日期：2026-11-05。工程版本：`0.18.0-fixed-voices`。

## 当前用户决定

- 暂停武器自己的四拍强弱、自动旋律与相位进度。保留素材，后续另行开发。
- 白点扫描到武器的起始格时，播放一次该武器固定音色。位置只影响触发时刻，不再移调。
- 同种武器的不同装备实例分别发声；占第1–2格、第3–4格时分别在第1、第3格触发，相隔0.25秒，尾音可重叠。
- 去掉武器卡片下方的拍序状态条；保留三轨8格和小白点。
- 后续集中制作10种武器，删除名单由用户决定。在名单确认前保留32种电子武器。
- 后续音色方向为钢琴、鼓、萨克斯、小提琴、吉他及部分电子音色。本轮没有下载或替换乐器采样。

筛选清单见 [武器—特效—音色对照](WEAPON_SELECTION_32_TO_10.md)。

## 已完成的代码修复

1. 当前生产调度固定使用各武器的 `voice_0.wav`，不再按所在格或扫描轮次轮换音高。声音每次经过保持同一音色与力度；原有充能仍限制真实弹体，不改变声音。
2. 去掉电子开火时叠播旧录音的路径。原生音轨中同一UID/扫描事件只混入一次，静音不再被额外录音绕过。
3. 同种武器以不同UID和各自扫描时刻混音，不按武器种类合并，也不会在后一声开始时停止前一声。
4. 武器音量乘在完整声音增益上。设为0时，升级和辅助音序声音也输出数字静音。
5. 播放期间调音量会异步替换实际正在播放的PCM；保留扫描位置、循环计数和暂停状态。
6. 从编辑器返回时，即使没有移动装备，也会采用新的轨道静音/独奏设置；静音只影响声音。
7. 试射使用自己的音频准备任务，避免覆盖或取消正式战斗的待准备音轨。音色图鉴改为试听一次固定声音，隐藏四拍图与多音高按钮。
8. 删除武器卡片拍序进度的绘制和更新逻辑，保留扫描小白点。

本轮保留了已制作的死亡低鼓、拾取声和临时护盾声。护盾声仍待用户提供更清晰视频后替换。
