# 律航 · BEATDRIFT

独立的 Godot 4.7.2 节拍射击肉鸽原型，暂定名。当前版本0.3：互动飞行主页 → Blender科幻都市“霓光港” → 飞船/驾驶员配置 → 中央漩涡出击 → 十波节拍战斗与装备商店 → 结算返回都市。

原《折界》保留在相邻的`Foldbound`目录，新工程独立制作，没有复用它的主世界、剧情、技能树或存档服务。运行时无需访问两个旧项目或Steam安装目录。

## 开始

双击`Play.cmd`启动。双击`Open_Editor.cmd`在Godot中打开，或手动导入本目录的`project.godot`并按F5。启动器优先使用本机已有Godot4.7.2；可以通过`GODOT_PATH`指定其他引擎路径。

默认全屏，逻辑画面1920×1080，桌面使用Forward+。设置、机库选择和最高分写入独立的`%APPDATA%/BeatDriftPrototype/settings.cfg`，不读写《折界》存档。测试用`--beatdrift-test`隔离玩家配置。

| 操作 | 功能 |
| --- | --- |
| 主页 WASD、鼠标 | 驾驶飞船、瞄准；射击菜单或点击菜单后由弹丸命中触发 |
| 主页 Enter | 进入都市 |
| 都市 WASD / Shift | 人物行走 / 奔跑 |
| 都市右键拖动 / 滚轮 | 环绕视角 / 镜头远近 |
| 都市 F | 靠近漩涡出击；靠近右侧机库更换配置 |
| 战斗 WASD / 方向键 | 自由飞行，镜头跟随 |
| 空格 | 短距离冲刺，短暂无敌；冷却取决于舰体 |
| E | 满充能时超载：清除当前敌弹、范围冲击、火力增强、恢复1生命 |
| Tab | 打开/关闭音序器；音乐与战斗暂停 |
| 拖动模块 | 在三轨之间交换位置，或由备用仓装入；宽装备不能跨轨 |
| 先点模块、再点格子 | 与拖放相同的编排操作 |
| 右键已装备格 | 卸下到备用仓；至少装备一件武器才能继续 |
| 属性 / 状态 / 增益 / 背包 / 音序 | 独立隐藏或显示；编辑与飞行分别记忆偏好 |
| 隐藏全部 / 显示全部 | 一键收起或展开状态栏，保留导航 |
| Esc | 暂停/继续；编辑器内返回 |
| F11 | 全屏/窗口切换 |
| R | 结算后重开 |

## 当前一局

三种原创舰体均保留白色六边核心，拥有不同轮廓、耐久、速度和初始模块：

| 舰体 | 生命 | 移速 | 伤害倍率 | 冲刺冷却 |
| --- | --- | --- | --- | --- |
| 白隼 · 均衡截击机 | 10 | 470 | 100% | 1.60秒 |
| 游隼 · 高速双翼机 | 8 | 560 | 92% | 1.15秒 |
| 磐石 · 重型炮舰 | 14 | 385 | 118% | 2.00秒 |

驾驶员可自由搭配舰体。回声在每小节末复奏最前方模块，造成半伤害并实际加入音符；伏特在冲刺结束后2秒内获得25%伤害与一枚额外弹丸；绫每收集16颗星屑恢复1生命，合并掉落仍按实际数量计算。

三轨各8格，同时从左向右循环。120 BPM，每格半拍，2秒一小节。装备占1—3格，只在首格发声和触发；不能跨轨或复制UID。移动模块同时改变出手时刻和音高；同轨、邻接、奇偶拍、首尾拍等规则由实际位置结算。

各舰体初始五个模块，优先位置为0、2、6、8、12，宽装备冲突时寻找合法空位。原六种武器继续保留：

| 武器 | 表现与用途 |
| --- | --- |
| 脉冲机炮 | 青色高速三连弹，自动瞄准 |
| 星砂霰弹 | 琥珀扇形弹，近距离集中命中 |
| 棱镜光束 | 紫色瞬发长束，贯穿整列 |
| 彗星导弹 | 粉色追踪弹，命中范围爆破 |
| 新星环炮 | 绿色全向弹幕，应对包围 |
| 跃迁电弧 | 蓝色连锁电弧，跳跃攻击敌群 |

另新增轨炮、回旋刃、轨道卫星、布雷、焰流和无人机等家族，总计32件独立武器。变体会改变弹数、穿透、追踪、范围、充能等实际规则。每件武器有独立音色和八音动机；1/2/4/8小节充能决定发射与旋律推进频率。全部武器音乐参数见[武器音乐矩阵](docs/WEAPON_MUSIC_MATRIX.md)。

前九波分别26、28、30、32、34、36、38、40、42秒；计划生成预算依次110、160、220、280、340、400、460、540、620，合计3130架普通编队敌机，另有分裂增援与Boss护航。预算属于我们原创配置，不是参考游戏的内部数据。

每四个音序格（1秒）在拍点生成一个编队，单批最多48架；开场前置舰队，约72%的接近方向偏向最近移动航向。V形、楔形、新月、双列、群簇、交叉楔、断弧、编织双列和六角星群逐波变化。普通机、装甲机、射手机、突进机、分裂机、哨戒机形成混合舰队。第4/8波另有精英；第10波是6800生命、半血转阶段的Boss，实际击破后即确认胜利，不要求清空全部护航。

生存波倒计时结束立即进入六商品补给商店，未击杀敌人撤退，不伪造击杀或掉落。已获得的地面掉落会结算收取。理论战斗时长约六分钟，实际还取决于Boss火力、编排和购物时间。

240件独立装备包括32武器、72改件、80节律、40生存、16核心，等级与品质副本不重复计数。所有辅助规则接入实际数值和事件；仅装入音序器的装备生效。备用仓上限64件。同类同级两件可合成一级，最高4级；回收退还星屑。每店至少一件武器，6件商品互不重复；刷新初始8星屑，每次递增4，下波重置。支持四维属性、暴击、护甲、生命恢复、移动、收集范围和幸运，以及治疗、冲刺护盾、击杀爆破和拍点反击导弹。完整目录见[240件装备](docs/ARSENAL_CATALOG.md)，计算与限制见[执行规则](docs/ARSENAL_ENGINE.md)。

战斗空间扩大为实际12288×12288，镜头随主机移动；舰体与普通机画面占比缩小，精英/Boss保留较大体型。敌群从当前视野外的安全距离进入，抵达世界边缘时会改换接近方向。普通波次以生存为目标，结算显示击破数、最高分和各武器伤害。

密集战斗使用96像素占用网格与扫掠线段碰撞，避免高速弹穿透。超过64架时，六种普通机切换共享网格实例绘制；弹丸按武器批量绘制，实体卫星、雷荚与回旋刃保留轮廓。数量硬上限为640敌机、1200友弹、700敌弹；掉落超过300个可视堆后合并数量，不吞掉已获得的星屑。具体测量见测试报告，不把上限视为稳定帧率保证。

## 霓光港与Blender源文件

主世界是独立3D出击港，中央为动态螺旋漩涡，右侧停机坪可配置飞船。分层金属广场、玻璃高塔、天桥、发光路标、反射水面与远处交通形成都市轮廓。人物为有骨骼Idle/Walk动画的原创飞行员模型。

`source_art/city/neon_city.blend`与`pilot.blend`保留可编辑模型；`assets/city/*.glb`为游戏导出。重建工具为`tools/build_neon_city.py`与`build_city_pilot.py`。运行游戏无需安装Blender。离开都市进入2D战斗时关闭其3D视口，避免同时支付两套场景渲染成本。详见`docs/NEON_HARBOR.md`。

## 音乐与表现

背景为程序绘制的低亮度太空、星点、行星边缘与透视网格，不进行黑白区域反转。白色主机和暖色敌弹保持辨识，彩色弹幕、爆破环、数字与碎片提供反馈，没有遮挡视野的烟幕。

伴奏与武器音符都在同一个原生WAV内合成，战斗和音乐读取同一份纯函数音序。128秒循环覆盖64小节，使充能8小节的重武器也能完整奏出自己的八音动机。编辑后保持播放相位，不允许重开编辑器刷第一拍。新增256个武器音高样本及32个伴奏样本，均为原创程序合成的22050Hz单声道PCM16；请保留`.wav.import`中的`compress/mode=0`。生成工具为`tools/export_arsenal_audio.gd`和`generate_arsenal_audio.py`。

这是“编排即音乐、节拍即火力”的程序合成音乐样机，鼓底仍为短循环，旋律由装备推进。尚未制作完整专辑、多曲目关卡和正式商业混音。命中、冲刺、爆破沿用已有样机音效，具体来源见`audio/CREDITS.md`。

## 验证

专项与完整流程见`docs/TEST_REPORT.md`。自动测试使用`--beatdrift-test`与隔离APPDATA，不写玩家配置；完整跑局使用无敌和辅助走位，不等同于真人难度验收。

源码入口：`scripts/main.gd`；舰体/驾驶员：`fleet_catalog.gd`；波次：`wave_plan.gd`；装备数据与纯音序：`arsenal_catalog.gd`与`arsenal_loadout.gd`；装备插画：`item_art.gd`；音乐：`music.gd`；都市：`neon_hub.gd`；批量舰队：`fleet_batch.gd`；状态栏/商店：`arsenal_screen.gd`。旧版`catalog.gd`/`loadout.gd`仅保留历史测试，不参与当前战斗。
