## 开始

双击`Play.cmd`启动。双击`Open_Editor.cmd`在Godot中打开，或手动导入本目录的`project.godot`并按F5。启动器优先使用本机已有Godot4.7.2；可以通过`GODOT_PATH`指定其他引擎路径。

获授权的参考音频采用逐条或整文件夹入库：可把文件拖到 `AudioLibrary_Add.cmd`，或把按用途分组的录音目录拖到 `AudioLibrary_ImportFolder.cmd`。资料库说明、授权状态和索引见[Groove Core 授权音频资料库](audio/library/groove_core/README.md)。

所有录像必须先提取完整音轨并完成全段波形、瞬态、响度区间和周期分析，再按完整强弱周期或有效瞬态截取。标准步骤和当前七条资源的分析结论见[录制音频处理手册](docs/AUDIO_PIPELINE.md)。

默认全屏，逻辑画面1920×1080，桌面使用Forward+。设置、机库选择、所选星球及逐星球成绩写入`%APPDATA%/BeatDriftPrototype/settings.cfg`。该目录名作为旧存档兼容标识保留，游戏内和桌面显示名称均为Groove Flight。测试用`--grooveflight-test`隔离玩家配置。

驾驶员可自由搭配舰体。回声在每小节末复奏最前方模块，造成半伤害并实际加入音符；伏特在冲刺结束后2秒内获得25%伤害与一枚额外弹丸；绫每收集16颗星屑恢复1生命；曜在每个小节第1拍获得20%伤害强化；凛在每个八小节乐句首拍获得1层护盾，最多叠3层。合并掉落仍按实际数量计算。

实战为三层，每层8格，同时从左向右扫描；当前每格0.1875秒，8格一轮1.5秒。装备占1—3格，只在首格触发；不能跨轨或复制UID。

V12 中，导弹、轨炮和雷荚按四拍组织声音：所在拍为重音，后续三个四分音符为轻拍；轻拍不会生成额外弹体或伤害，重弹仍受原本的小节充能门槛控制。商店详情会显示“重 - 轻 - 轻 - 轻”与真实充能档位。

每次普通波结束后，补给站顶部都会提供一次免费的三选一基础强化。生命、装甲、移速、单发伤害、暴击、再生、拾取、幸运或主属性会直接进入战斗计算；选择强化后才能继续下一波，装备购买仍由六件商品负责。

标准难度下，普通敌机生命从1倍逐步增至2.9倍，接触/弹幕伤害从1倍增至2.75倍，移速从1倍增至1.24倍，弹速从1倍增至1.27倍。星屑倍率1—1.95倍并保留小数余量。高压模式再乘耐久1.18、Boss生命1.30、伤害1.14、移速1.05、弹速1.08、编队预算1.18。每星球的波次、数值、任务与战术提示见[行星航线说明](docs/PLANET_ROUTES.md)。

每四个音序格（1秒）在拍点生成一个编队，单批最多48架；开场前置舰队，约72%的接近方向偏向最近移动航向。十一种阵形按星球重新组合，编队成员以0—0.42秒错峰跃迁，并以弯曲航线切入。普通机、装甲机、射手机、突进机、分裂机、哨戒机、穿棱机与镜像机八类普通敌机使用不同轮廓和攻击方式。前期星球预约1次精英，后期2次；高压模式还会在更多波次加入精英。最后一波为该星球的Boss，实际击破即确认胜利。

生存波倒计时结束立即进入六商品补给商店，未击杀敌人撤退，不伪造击杀或掉落。已获得的地面掉落会结算收取。固定生存段从水星120秒逐步增至海王星333秒，另加实际Boss战和购物时间。通关后记录该星球次数、最高分和最快战斗时间，结算可前往下一颗星球、重试或返回都市。

246件独立装备包括38个武器条目、72改件、80节律、40生存、16核心。试玩构建中32把电子武器可用，6个录音品质条目隐藏并保留档案。所有辅助规则接入实际数值和事件；仅装入音序器的装备生效。备用仓上限64件。同类同级两件可合成一级，最高4级；回收退还星屑。每店至少一件可用武器，6件商品互不重复；刷新初始8星屑，每次递增4，下波重置。完整目录见[246件装备](docs/ARSENAL_CATALOG.md)。

战斗空间扩大为实际12288×12288，镜头随主机移动；舰体与普通机画面占比缩小，精英/Boss保留较大体型。敌群从当前视野外的安全距离进入，抵达世界边缘时会改换接近方向。普通波次以生存为目标，结算显示击破数、最高分和各武器伤害。

密集战斗使用96像素占用网格与扫掠线段碰撞，避免高速弹穿透。超过64架时，八种普通机切换共享网格实例绘制；弹丸按武器批量绘制，实体卫星、雷荚与回旋刃保留轮廓。数量硬上限为640敌机、4096友弹、700敌弹；掉落超过300个可视堆后合并数量，不吞掉已获得的星屑。具体测量见测试报告，不把上限视为稳定帧率保证。

## 霓光港与Blender源文件

主世界是独立3D出击港，中央动态漩涡打开星球航图，右侧停机坪配置飞船。分层金属广场、玻璃高塔、天桥、发光路标、反射水面与远处交通形成都市轮廓。人物为有骨骼Idle/Walk动画的原创飞行员模型。

## 音乐与表现

星图包含真实3D球体、程序表面材质、太阳日冕、土星环、地球卫星和轨道。显示比例便于点选，非天文距离比例。战斗使用独立的高清行星表面、银河背景、云影、大气边缘、海洋反光、夜景与前后遮挡的星环。贴图由Solar System Scope / INOVE提供，CC BY4.0，源尺寸与许可见[素材记录](assets/planets/CREDITS.md)。白色主机和暖色敌弹保持辨识，彩色弹幕、爆破环、数字与碎片提供反馈。

当前原生混音已关闭程序底层伴奏和节拍鼓床，只保留武器、命中、护盾与编辑音乐事件。战斗使用3层8格、每格0.125秒、一轮1秒；32把电子武器重新启用，两把录音武器暂时隐藏。生成与来源记录仍保存在`audio/weapon_codex.json`。

V12 历史上的程序鼓组已从V15实战中关闭。现在敌机实际受伤时会触发重低频撞击“咚”，并为我方战斗机刷新3秒无敌护盾；护盾带双层球壳、六边形边界、旋转能量环和剩余时间提示。护盾与受击音效来自已入库的 `events_enemy_collision`。

这是“编排即音乐、节拍即火力”的程序合成音乐样机，鼓底仍为短循环，旋律由装备推进。尚未制作完整专辑、多曲目关卡和正式商业混音。命中、冲刺、爆破沿用已有样机音效，具体来源见`audio/CREDITS.md`。

## 验证

专项与完整流程见`docs/TEST_REPORT.md`。自动测试使用`--grooveflight-test`与隔离APPDATA，不写玩家配置；完整跑局使用无敌和辅助走位，不等同于真人难度验收。
