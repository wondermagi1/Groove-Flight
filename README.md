# 律航 · BEATDRIFT

独立的 Godot 4.7.2 节拍射击肉鸽原型，暂定名。白色六边形主机、深色太空、彩色武器与粒子。以《音序核心》的公开玩法和用户实机画面为参考：编排模块，武器随拍自动开火，移动躲弹，波间重组，最后击破Boss。

原《折界》保留在相邻的`Foldbound`目录，新工程独立制作，没有复用它的主世界、剧情、技能树或存档服务。运行时无需访问两个旧项目或Steam安装目录。

## 开始

双击`Play.cmd`启动。双击`Open_Editor.cmd`在Godot中打开，或手动导入本目录的`project.godot`并按F5。启动器优先使用本机已有Godot4.7.2；可以通过`GODOT_PATH`指定其他引擎路径。

默认全屏，逻辑画面1920×1080。设置和最高分写入独立的`%APPDATA%/BeatDriftPrototype/settings.cfg`，不读写《折界》存档。

| 操作 | 功能 |
| --- | --- |
| WASD / 方向键 | 飞行，镜头跟随 |
| 空格 | 短距离冲刺，短暂无敌，1.6秒冷却 |
| E | 满充能时超载：清除当前敌弹、范围冲击、火力增强、恢复1生命 |
| Tab | 打开/关闭音序器；音乐与战斗暂停 |
| 拖动模块 | 在两轨之间交换位置，或由备用仓装入 |
| 先点模块、再点格子 | 与拖放相同的编排操作 |
| 右键已装备格 | 卸下到备用仓；至少装备一个模块才能继续 |
| Esc | 暂停/继续；编辑器内返回 |
| F11 | 全屏/窗口切换 |
| R | 结算后重开 |

## 当前一局

两轨各8格，同时从左向右循环。120 BPM，每格半拍，2秒一小节。每个模块独立拥有编号和等级，不能复制同一模块到多个格子。移动模块会同时改变实际出手顺序、武器音色和旋律。

初始五个模块：两件脉冲机炮、一件霰弹、一件棱镜光束、一件新星环炮。六种武器都已实现真实伤害：

| 武器 | 表现与用途 |
| --- | --- |
| 脉冲机炮 | 青色高速三连弹，自动瞄准 |
| 星砂霰弹 | 琥珀扇形弹，近距离集中命中 |
| 棱镜光束 | 紫色瞬发长束，贯穿整列 |
| 彗星导弹 | 粉色追踪弹，命中范围爆破 |
| 新星环炮 | 绿色全向弹幕，应对包围 |
| 跃迁电弧 | 蓝色连锁电弧，跳跃攻击敌群 |

前五波分别18、22、24、26、28秒；倒计时结束立即进入三选一奖励，剩余敌人撤退，不伪造击杀或掉落。第3、5波有精英。第6波是3400生命、半血转阶段的Boss，必须实际击破才能胜利。

奖励包含新模块、模块升级、全局火力与构筑羁绊。模块最高四级。已有六类独立增益：伤害、额外弹丸、同类相邻连奏、异类相邻和弦、吸取续航、超载回路。星屑用于花费8点刷新奖励；血包和吸取增益可以恢复生命。

世界是实际8192×8192二维空间，镜头随主机移动；敌人从当前视野外围进入。普通波次以生存为目标，避免跑遍大地图找最后一只敌人。结算显示击破数、最高分和各武器伤害。

## 音乐与表现

背景为程序绘制的低亮度太空、星点、行星边缘与透视网格，不进行黑白区域反转。白色主机和暖色敌弹保持辨识，彩色弹幕、爆破环、数字与碎片提供反馈，没有遮挡视野的烟幕。

伴奏与武器音符都在同一个原生WAV循环内合成，战斗读取该音轨的实际播放时钟。编辑时保持播放相位，不允许重开编辑器刷第一拍。49条原始伴奏/音符素材使用未压缩PCM16导入；请保留`.wav.import`中的`compress/mode=0`。

这是2秒短循环的程序合成音乐样机，目的是验证“编排即音乐、节拍即火力”。尚未制作长曲、多曲目、正式编曲和完整商业音效混音。命中、冲刺、爆破另参考两个旧项目，具体来源见`audio/CREDITS.md`。

## 验证

专项与完整流程见`docs/TEST_REPORT.md`。自动测试使用`--beatdrift-test`与隔离APPDATA，不写玩家配置；完整跑局使用无敌和辅助走位，不等同于真人难度验收。

源码入口：`scripts/main.gd`；模块与羁绊：`scripts/loadout.gd`；音乐调度：`scripts/music.gd`；波次/武器数据：`scripts/catalog.gd`；界面：`scripts/ui.gd`。没有旧技能树的隐含开关。
