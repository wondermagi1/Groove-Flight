# Groove Flight

长期维护的[武器特效与音频对应表](docs/WEAPON_VFX_AUDIO_REFERENCE.md)：24种现役武器的发射形式、运动、光色、乐器音色与原声试听。以后武器迭代与本表同步提交更新。

当前版本 **0.51.0-music-piano**：左手WASD移动，右手H/J/K/L四键跟随《Filaments》音乐琴块，支持短按、长按到尾与双键同时按。错键、漏按或长按中断，本次齐射失败。武器保留原1.5秒音序充能资格，实际发射交给下一音乐点；原24武器/288WAV、弹数伤害与敌群/Boss保留。见[V51玩法与验证](docs/V51_MUSIC_CHART_PIANO.md)和[现役武器表](docs/WEAPON_VFX_AUDIO_REFERENCE.md)。

历史Windows x64独立Demo：`dist/GrooveFlight_Demo_v0.49.0_Windows_x64.zip`，尚不含V50/V51琴块输入。完整解压后双击`GrooveFlightDemo.exe`；无需安装Godot/Python，另附兼容模式入口。运行、重建与验证见[Demo说明](docs/WINDOWS_DEMO.md)。

音频与设置基础：护盾反馈按用户要求裁成干净的一击，去掉末尾小声音；设置中有总音量、背景音乐、武器声音、击杀鼓点、拾取、受击护盾、命中爆炸、界面和独立警报9项控制，即时生效、0%静音并自动保存。见[分类音量说明](docs/V26_AUDIO_CONTROLS.md)。

当前24种武器共288份样本：192份作曲音高＋96份四档演奏。主乐器已覆盖钢琴、小提琴、中提琴、大提琴、竖琴、单簧管和长笛7类；后续统一13乐器框架见[配器方向](docs/ORCHESTRAL_AUDIO_DIRECTION.md)。

V24特效基础：全部16种武器按类别优化，13种实体弹各自拥有喷射时差、初速、质量与实际受力轨迹；新星环炮各弹独立弯转，星冕加入呼吸与跟随惯性，七彩折光匣改为四斜向摇摆的彩色羽状实体弹流。激光、电弧保持各自形式。地平线两翼喷流、机尾U形羽流、射程后缩小退场、属性/品质加弹、固定声音与同种重奏保留，当前循环为1.5秒。见[本版说明与预览](docs/V24_ALL_WEAPON_MOTION.md)、[敌群机制文档](docs/ENEMY_FORMATIONS_AND_ENCIRCLEMENT.md)和[当前接手说明](docs/CURRENT_HANDOFF.md)。

后续制作遵循[当前声音与时序约定](docs/RHYTHM_CONTRACT.md)。V36启用纯音频演奏力度乐句；音高、伤害与弹数不跟随轻重轮换，旧拍序条与自动旋律仍不启用。

项目已于2026-11-04正式统一使用 Groove Flight 名称；旧存档与乐谱标识的兼容说明见[品牌更名记录](docs/BRAND_RENAME.md)。

## 开始

双击`Play.cmd`启动。双击`Open_Editor.cmd`在Godot中打开，或手动导入本目录的`project.godot`并按F5。启动器优先使用本机已有Godot4.7.2；可以通过`GODOT_PATH`指定其他引擎路径。

获授权的参考音频采用逐条或整文件夹入库：可把文件拖到 `AudioLibrary_Add.cmd`，或把按用途分组的录音目录拖到 `AudioLibrary_ImportFolder.cmd`。资料库说明、授权状态和索引见[Groove Core 授权音频资料库](audio/library/groove_core/README.md)。

所有录像必须先提取完整音轨并完成全段波形、瞬态、响度区间和周期分析，再按完整强弱周期或有效瞬态截取。标准步骤和当前七条资源的分析结论见[录制音频处理手册](docs/AUDIO_PIPELINE.md)。

默认全屏，逻辑画面1920×1080，桌面使用Forward+。设置、机库选择、所选星球及逐星球成绩写入`%APPDATA%/BeatDriftPrototype/settings.cfg`。该目录名作为旧存档兼容标识保留，游戏内和桌面显示名称均为Groove Flight。测试用`--grooveflight-test`隔离玩家配置。

## 当前一局

星图选星球和难度，进入战前流派选择，确认后开始本局。实弹流18种（含导弹和实体棱镜）、激光3种、电链3种；本局只获取本流派武器/专属道具以及适用的通用生存组件。商店固定3武器＋3道具，锁定保留位置和价格；点击装备固定详情和合成对象，拖动可交换。

| --- | --- |
| 实弹 | 脉冲机炮 A3、苍穹轨炮 B4–B5 |
| 激光 | 棱镜光束 A3–A4、曦光束阵 B4–B5 |

流萤织雨不再免费起手，保留实弹池购买。舰体影响耐久、移速、伤害及冲刺；有效非武器组件保留。波间不重置玩家编排。结算重试重新选流派。

三轨各8格，每格0.1875秒、每轮1.5秒。装备宽1–3格，仅首格在实际充能完成时触发；等待轮不新增声音。充能支持1/2/3/4/6/8轮。同种武器不同格独立重奏，每次齐射一声；力度乐句改变演奏，不改变音高/伤害/弹数。

八颗星球都可选，均为七普通波＋死亡结算的Boss。普通波20/20/20/27/27/33/40秒。商店不限时；含购物5–6分钟是典型目标，实际受构筑、Boss和停留影响。每波免费三选一强化，主属性项+5。当前数值与路线见[生产快照](docs/data-v43/run-foundation.json)。

矩阵或圆形同模组敌群从上方/左上/右上安全区域预警后生成，保持玩家净空；随后每个敌机独立分散、绕行、包围，近处形成弧/扇压力。普通敌机不发射子弹，持续行进，每0.25秒更新安全路线，平均行进速度保持基础速度的1.2倍。原生群体内核保持避让与完整个体；局部拥堵仍可减速或等待。敌机上限1024、友弹4096，上限不代表持续帧率保证。

实体弹保持独立出膛/速度/质量/受力、真实曲线尾迹、完整射程后才缩小退场。激光每1能量+1折射，电链每5能量+1传导、击杀向最近3个可用目标分流。西风仅实弹流未拥有时在第三/四波初始店保证，完整唯一不升级；万花筒4轮充能，96基础弹，同轨自由实体弹继承旋转甩射形式。

## 霓光港与Blender源文件

主世界是独立3D出击港，中央动态漩涡打开星球航图，右侧停机坪配置飞船。分层金属广场、玻璃高塔、天桥、发光路标、反射水面与远处交通形成都市轮廓。人物为有骨骼Idle/Walk动画的原创飞行员模型。

`source_art/city/neon_city.blend`与`pilot.blend`保留可编辑模型；`assets/city/*.glb`为游戏导出。重建工具为`tools/build_neon_city.py`与`build_city_pilot.py`。运行游戏无需安装Blender。离开都市进入2D战斗时关闭其3D视口，避免同时支付两套场景渲染成本。详见`docs/NEON_HARBOR.md`。

## 音乐与表现

星图包含真实3D球体、程序表面材质、太阳日冕、土星环、地球卫星和轨道。显示比例便于点选，非天文距离比例。战斗使用独立的高清行星表面、银河背景、云影、大气边缘、海洋反光、夜景与前后遮挡的星环。贴图由Solar System Scope / INOVE提供，CC BY4.0，源尺寸与许可见[素材记录](assets/planets/CREDITS.md)。白色主机和暖色敌弹保持辨识，彩色弹幕、爆破环、数字与碎片提供反馈。

当前背景为 Scott Buckley 的 Filaments（339.88秒，CC BY4.0）。9类音量独立即时调整并保存；调音量/暂停/恢复设置不重启背景运输。武器采用四档实际演奏样本，长充能现役素材约0.5秒，图鉴/商店/战斗同源。击杀低鼓、清脆拾取、单次干净受击护盾分开播放，来源与授权见 `audio/CREDITS.md`。
