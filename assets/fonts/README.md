# Interface fonts

Oxanium (headings) and JetBrains Mono (numbers / countdown / Combo) are bundled unchanged under SIL Open Font License 1.1. Their full licenses accompany the font files. Sources and SHA256 hashes are in [SOURCES.json](SOURCES.json).

Chinese body text uses the existing system-font fallback. Chinese titles prefer DengXian before Microsoft YaHei / Noto Sans CJK SC; this avoids using decorative Latin glyphs for Chinese. No Windows system font file is redistributed.
